# 01. 요구사항 인벤토리 (PM-INV)

- 입력: IN-REQ `docs/00-inputs/ubuntubooks-user-requirements-raw.md` (이 문서 작성 후 원문은 다시 읽지 않는다), IN-KANT `docs/00-inputs/kant-rubric.md`
- 규칙: 원문 표현을 그대로 인용한다(요약·해석 금지). 이후 모든 문서는 REQ-ID로만 참조한다.
- 태그: `[기능] [비기능] [제약] [감성/UX 의도] [운영] [요청-견적/일정]`
- 번호 대역: 0xx 머리말 / 01x 기본 공간·서가 / 02x 로그인 / 03x~04x 감성 인터랙션 / 05x 관리자 / 06x 맺음말 / T 팀 제약
