## 2. 가정·모호성 목록

### ASM-01 (모호 → 확정)  ← REQ-010, REQ-047
- 내용: 봇이 "회원과 같은 규칙으로 점프한다"고만 되어 있고, 언제 누가 봇을 점프시키는지 없음
- 위험: 봇이 점프하지 않으면 봇만 있는 팀은 이길 수 없고, 자동 점프면 서버가 스스로 움직이는 기능이 추가됨 (일정 영향)
- 질문: Q-01
- 영향 계층: [모듈 협력 구조]

### ASM-02 (누락 → 확정)  ← REQ-028, REQ-033
- 내용: 게임은 "점프 5회 선착"으로만 끝남. 참가자가 모두 떠나면 매치가 계속 `게임 중`으로 남음
- 위험: 끝나지 않은 매치가 쌓이고, 그 회원들은 "게임 중"이라 다시 대기열에 등록할 수 없음 (REQ-022) (D4)
- 질문: Q-02
- 영향 계층: [모듈 협력 구조]

### ASM-03 (누락 → 확정)  ← REQ-022, REQ-023, REQ-034
- 내용: 취소한 회원이 같은(또는 다른) 대기열에 다시 등록할 수 있는지 없음
- 위험: 금지하면 실수로 취소한 회원이 막히고, 허용하면 등록·취소 반복으로 대기 순서를 흔들 수 있음
- 질문: Q-03
- 영향 계층: [모듈 협력 구조]

### ASM-04 (암묵적 전제)  ← REQ-022
- 내용: "게임 중인 회원의 등록은 거부"이므로, 게임이 끝난 회원은 바로 다시 등록할 수 있다고 전제됨
- 위험: 낮음
- 처리: (확정) REQ-022의 반대 조건으로 해석. 별도 질문 없음

### ASM-05 (모호 → 확정)  ← REQ-016
- 내용: "정해진 최소 길이"의 값이 없음
- 질문: Q-05

### ASM-06 (모호 → 확정)  ← REQ-045
- 내용: "짧은 지연"의 목표값이 없음. 측정할 수 없는 기준은 AC로 쓸 수 없음
- 질문: Q-06 (갱신 방식은 →ARCH-03)

### ASM-07 (모호)  ← REQ-013~015
- 내용: 닉네임 길이·허용 문자가 없음
- 처리: (확정) 자율 결정 D-005 — 2~12자, 한글·영문·숫자

### ASM-08 (모호)  ← REQ-043, REQ-T11
- 내용: 목록 페이지 크기 기본값·상한이 없음
- 처리: (확정) 자율 결정 D-006 — 기본 20건, 상한 100건, 기본 정렬은 종료 시각 최신순

### ASM-09 (누락)  ← REQ-049
- 내용: 이벤트 로그를 얼마나 보관하는지 없음
- 처리: (확정) 자율 결정 D-007 — 시연용이므로 보관 기간 제한 없음

### ASM-10 (암묵적 전제)  ← REQ-028, REQ-029
- 내용: 두 참가자가 거의 동시에 5회를 채우면, 서버가 먼저 기록한 점프가 승리라고 전제됨
- 위험: 처리 순서가 보장되지 않으면 승자가 둘이 될 수 있음 (INV 위반)
- 처리: (확정) "처음 채운" = 서버가 먼저 기록한 점프. 보장 방식은 →ARCH-02

### ASM-11 (암묵적 전제)  ← REQ-020~022, REQ-048, REQ-053
- 내용: 도전 A 전에도 정원 초과·중복 대기가 데이터에 남지 않는다고 전제됨
- 위험: 동시 등록 시 정원 초과 (D4)
- 처리: (확정) 필수 단계에서도 데이터 무결성은 지킨다. 방식은 →ARCH-01

### ASM-12 (암묵적 전제)  ← REQ-011, REQ-043
- 내용: 비로그인 방문자가 매치 히스토리의 참가자 닉네임을 볼 수 있다고 전제됨
- 위험: 낮음 (닉네임 외 개인정보 없음)
- 처리: (확정) 공개. 닉네임 외 회원 정보는 노출하지 않음

### ASM-13 (누락)  ← REQ-006
- 내용: 회원 탈퇴·정보 수정·비밀번호 변경이 없음
- 처리: 요구사항에 없으므로 P4에서 Won't로 분류 (질문 없음)

### ASM-14 (누락)  ← REQ-013, REQ-T13
- 내용: 로그인 실패 횟수 제한이 없음
- 위험: 비밀번호 무차별 대입 (D4). 시연 환경이라 영향은 낮음
- 처리: 요구사항에 없으므로 P4에서 Won't로 분류하고 리스크로 남김 (질문 없음)

### ASM-15 (모호)  ← REQ-007, REQ-050, REQ-054
- 내용: 운영자 기능의 "히스토리 다운로드"(REQ-007)가 도전 B(REQ-054)에만 구체적으로 있음
- 처리: 다운로드는 도전 B에 속한다고 보고, 도전 B 채택 여부(D-002)에 따라 범위를 정함

### ASM-16 (모호 → 확정)  ← REQ-035, REQ-056
- 내용: 대기 타임아웃 시간이 없음 (도전 D)
- 질문: Q-07 (응답 없음 판정 방식은 →ARCH-05)

### ASM-17 (모호 → 확정)  ← REQ-043
- 내용: "끝난 매치 목록"인데 "상태로 필터"가 있음. 끝난 매치만 보이면 상태 필터가 의미 없음
- 질문: Q-04
