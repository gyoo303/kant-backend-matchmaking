## 2. 가정·모호성 목록

### ASM-01 (모호 → 확정)  ← REQ-015, REQ-114
- 내용: 게임 시작을 누가 요청할 수 있는지 미정. 원문 기본안은 "현재 방장만"
- 위험: 참가자 누구나 허용하면 4명이 모이는 순간 다른 참가자가 방장 의사와 무관하게 해산시킬 수 있음
- 질문: Q-01
- 영향 계층: [모듈 협력 구조]

### ASM-02 (모호 → 확정)  ← REQ-014, REQ-113
- 내용: 팀 변경을 본인만 할 수 있는지, 방장이 다른 참가자의 팀도 바꿀 수 있는지 미정
- 위험: 방장의 타인 변경을 허용하면 "타인 리소스 변경" 권한 규칙과 거부 시나리오가 늘어남 (D4)
- 질문: Q-02
- 영향 계층: [모듈 협력 구조]

### ASM-03 (모호 → 확정)  ← REQ-024, REQ-029, REQ-112
- 내용: 생성자·신규 참가자의 최초 팀을 정하는 방식이 미정. 원문 기본안은 "직접 선택"이지만, 생성 입력은 "제목 하나"(REQ-024)로 되어 있어 서로 어긋남
- 위험: 직접 선택이면 생성·참가 요청에 팀 입력이 추가되고, 선택한 팀이 그사이 가득 차는 거부 경로가 하나 더 생김
- 질문: Q-03
- 영향 계층: [모듈 협력 구조]

### ASM-04 (누락 → 확정)  ← REQ-021, REQ-023, REQ-115
- 내용: "로그인 식별 정보"와 "닉네임"을 따로 저장한다고만 되어 있고, 가입 입력·중복 기준·길이·비밀번호 규칙이 없음
- 위험: 도메인 생성자 검증 규칙(EV-02)과 AC를 쓸 수 없음
- 질문: Q-04
- 영향 계층: [어플리케이션]

### ASM-05 (모호 → 확정)  ← REQ-073, REQ-T16, EV-08
- 내용: 발제는 "메인/목록/현황 대시보드" 3화면을 요구하지만, 원문 화면은 회원가입·로그인·공개 방 목록·방 상세·내 기록 5개
- 위험: 3화면 대응이 정해지지 않으면 EV-08 증빙과 시연 흐름이 흔들림
- 결정: D-012 [APPROVED] — 메인 = SCR-03 공개 방 목록, 목록 = SCR-05 내 기록, 현황 대시보드 = SCR-04 방 상세
- 영향 계층: [어플리케이션]

### ASM-06 (모호 → 확정)  ← REQ-098~104, REQ-107, REQ-T21, REQ-T22
- 내용: 원문은 동시 요청 무결성을 필수 규칙처럼 적었지만, 발제는 동시성 제어를 도전 A(필수 완료 후)로 둠
- 위험: 무결성을 도전으로 미루면 정원 초과·중복 참가가 필수 시연에서 생길 수 있고, 필수로 당기면 일정이 늘어남
- 결정: D-018 [APPROVED] — 동시 요청 무결성(잠금·부분 유니크 인덱스)은 도전 A(M6). 필수는 순차 요청 기준으로 도메인이 규칙을 검사한다
- 영향 계층: [모듈 협력 구조]

### ASM-07 (암묵 → 확정)  ← REQ-010
- 내용: 비로그인 상태로 서비스 화면에 들어오면 로그인 화면으로 보낸다고 전제
- 결정: [자율] D-005

### ASM-08 (모호 → 확정)  ← REQ-033, REQ-034
- 내용: 이미 참가 중인 같은 방에 다시 참가를 요청했을 때 성공으로 볼지 거부할지 없음
- 결정: [자율] D-006 — 기존 참가를 그대로 두고 성공으로 응답(새 기록 없음)

### ASM-09 (모호 → 확정)  ← REQ-055, REQ-117
- 내용: 이용 이력 페이지 크기와 동률 정렬 방향 없음
- 결정: [자율] D-007

### ASM-10 (누락 → 확정)  ← REQ-020
- 내용: 회원 탈퇴·정보 수정 요구 없음
- 결정: [자율] D-008 — Won't (원문·발제 근거 없음)

### ASM-11 (누락 → 확정)  ← REQ-020, REQ-T13
- 내용: 로그인 무차별 대입 방어 요구 없음
- 결정: [자율] D-008 — Won't (원문·발제 근거 없음, 시연용)

### ASM-12 (모호 → 확정)  ← REQ-057, REQ-118
- 내용: 삭제 방 보관 정보의 과거 제목·닉네임 표시 방식 없음
- 결정: [자율] D-009 — 삭제된 방은 제목을 바꿀 수 없으므로 저장된 제목을 그대로 보여 주고, 사람 정보는 본인 기록만 보여 준다

### ASM-13 (모호 → ARCH)  ← REQ-063, REQ-T12
- 내용: 팀 정원 초과·시작 조건 불충족·시작 권한 없음의 응답 코드가 설계 단계로 넘어가 있음
- PM 권장: 도메인 규칙 위반은 발제 기준대로 400. 권한 코드는 ARCH가 정함
- 이관: ARCH-Q-01

### ASM-14 (암묵 → 확정)  ← REQ-036
- 내용: "두 팀"의 이름이 없음
- 결정: [자율] D-010 — A팀·B팀

## 답변

- Q-01 → A. 현재 방장만 게임 시작을 요청한다 (사용자, 2026-10-28)
- Q-02 → A. 참가자는 본인 팀만 바꾼다. 방장도 다른 참가자의 팀은 바꿀 수 없다 (사용자, 2026-10-28)
- Q-03 → A. 생성·참가 때 서버가 자동 배정한다. A팀에 자리가 있으면 A팀, 없으면 B팀에 배정한다(D-024, 2026-10-30). 생성 입력은 제목 하나로 유지한다 (사용자, 2026-10-28)
