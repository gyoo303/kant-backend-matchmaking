# 03. 도메인 정의 (PM-DOMAIN)

- 입력: PM-INV, PM-ASM(답변 포함). UX-CTX-ORCH 미배포.
- 구현(스키마·라이브러리)은 정하지 않는다. 영문 식별자는 하위 단계의 **이름 후보**다.

## 1. Use Case 한 문장 (KANT-C1)
대전 어은동 동네서점 우분투북스가 **자연·식문화·생태·로컬 테마의 책**을, 빠른 배송보다 **책방지기와 천천히 관계 맺기를 원하는 독자**에게 파는 온라인 책방이다. 일반 책 구매(장바구니·결제)와, 독자가 손편지를 보내면 책방지기가 책을 골라 블라인드로 보내 주는 **월간 편지 구독**을 함께 제공한다. (REQ-001~004, REQ-010, REQ-017, REQ-018, REQ-031)

## 2. 액터와 목표

| 액터 | 식별자 후보 | 목표 | 근거 |
|---|---|---|---|
| 방문자(비회원) | `Visitor` | 책방 소개·테마 서가·책 상세를 둘러본다 | REQ-010~013, D-015 |
| 손님(회원) | `Reader` | 책을 사고, 편지로 구독을 신청하고, 언박싱하고, 메모를 남기고, 해지한다 | REQ-017, REQ-018, REQ-031~048 |
| 책방지기(관리자, 1명) | `Bookkeeper` | 책을 등록·관리하고, 편지를 읽고 책을 매칭해 발송하고, 일반 주문을 발송하고, 주소록을 받는다 | REQ-050~056, Q-005 |
| 결제사 | `PaymentProvider` | 카드·간편결제 승인 | REQ-018, →A-01 |
| 소셜 로그인 | `OAuthProvider`(카카오·네이버) | 회원 식별 | REQ-021, →A-02 |

택배사 연동은 없다(REQ-034). 발송 사실은 책방지기가 직접 기록한다.

## 3. 용어집

| 용어 | 식별자 후보 | 정의 | 근거 |
|---|---|---|---|
| 책 (상품) | `Product` | 판매·구독 매칭에 함께 쓰는 책 1종. §4 속성 | REQ-010, REQ-053, KANT-C5 |
| 테마 | `Theme` | 자연·식문화·생태·로컬 4개 고정. 책 1권은 테마 1개에 속함 | REQ-010, REQ-011 |
| 책방지기 노트 | `bookkeeperNote` (Product 속성) | 책방지기가 쓴 추천 글. 상세 화면 최상단 | REQ-013 |
| 재고 | `stock` (Product 속성) | 남은 권수. 0이면 품절 | Q-006 |
| 장바구니 | `Cart` / `CartItem` | 회원별 담아 둔 책과 수량 | REQ-017 |
| 주문 | `Order` | 장바구니에서 결제한 일반 구매 1건 | REQ-018 |
| 결제 | `Payment` | 주문 또는 구독 회차 1건에 대한 결제 | REQ-018, Q-001 |
| 배송지 | `ShippingAddress` | 받는 사람·주소·연락처 | REQ-056, ASM-003 |
| 편지 구독 | `Subscription` | 손님 1명의 월간 구독 관계. 첫 회차 결제 시 시작, 해지 시 끝 | REQ-031, Q-001 |
| 회차 | `SubscriptionRound` | 한 달 1번. **편지 1통 = 결제 1번 = 발송 1건 = 언박싱 코드 1개** | Q-001, Q-002 |
| 손편지 | `ReaderLetter` | 손님이 회차마다 쓰는 자유 글(마음 날씨, 읽고 싶은 책의 결) | REQ-032, Q-002 |
| 우체통에 편지 넣기 | `postLetter` (행동) | 편지 제출. 봉투가 닫히며 우체통으로 들어가는 연출 | REQ-033 |
| 창가 등불 | `WindowLamp` (회차 표시 상태) | 손님 마이페이지의 서점 창가 그림 상태: 어두움 / 촛불 / 우체통 불빛 | REQ-034~037, D-010 |
| 답장 편지 | `ReplyLetter` | 책방지기가 회차마다 쓰는 답장 글 | REQ-042, REQ-054 |
| 엽서 사진 | `PostcardPhoto` | 책방지기 손글씨 엽서 사진 | REQ-054 |
| 힌트 문장 | `Teaser` | 발송 후 손님에게 보이는 짧은 티저 | REQ-039, REQ-055 |
| 블라인드 북 | `BlindBook` (표시 방식) | 언박싱 전 책 표지·제목을 실루엣으로 가린 표시 | REQ-038 |
| 언박싱 코드 | `UnboxingCode` | 발송 시 자동 생성되는 6자리 숫자, 상자 속 카드에 손으로 적음 | REQ-041, REQ-055 |
| 언박싱 | `unbox` (행동) | 코드 입력 성공 시 책·답장 편지·엽서 사진 공개 | REQ-042 |
| 서가 메모 | `ShelfMemo` | 언박싱된 책에 남기는 100자 이하 비공개 한 줄 감상 + 날짜 | REQ-044, D-012 |
| 작별 안부 | `FarewellNote` | 해지 시 손님이 자유롭게 남기는 글 | REQ-047 |
| 마지막 인사 편지 | `FarewellLetter` | 해지 화면에 먼저 보이는 책방지기 공통 인사 | REQ-046, D-013 |
| 주소록 | `AddressBookExport` | 발송 대기 건의 배송지 엑셀 다운로드 | REQ-056, D-014 |

## 5. 비즈니스 상태 흐름

### 5.1 주문 `Order` (일반 구매)
| 상태 | 손님 화면 문구 | 다음 상태 | 전이 주체·조건 |
|---|---|---|---|
| 결제 대기 `PENDING_PAYMENT` | 결제 대기 | 결제 완료 / 취소 | 결제사 승인 / 손님 취소 |
| 결제 완료 `PAID` | 준비 중 | 발송됨 | 책방지기 발송 처리 |
| 발송됨 `SHIPPED` | 발송됨 | — | 종료 |
| 취소 `CANCELED` | 취소됨 | — | 결제 전 취소만(결제 후 환불은 범위 밖, 의뢰인 수동 처리) |

- 결제 완료 시 재고가 주문 수량만큼 줄어든다(INV-05).

### 5.2 편지 구독 `Subscription`
| 상태 | 다음 상태 | 전이 주체·조건 |
|---|---|---|
| 구독 중 `ACTIVE` | 해지됨 | 첫 회차 결제 완료 시 시작. 손님이 [구독을 마무리합니다] 누르면 즉시 해지 |
| 해지됨 `ENDED` | 구독 중 | 손님이 다시 편지를 보내고 결제하면 새 구독으로 시작 |

### 5.3 회차 `SubscriptionRound` (창가 등불 포함)
| 상태 | 창가 등불 | 다음 상태 | 전이 주체·조건 |
|---|---|---|---|
| 결제 대기 `PENDING_PAYMENT` | (표시 안 함) | 편지 도착 | 결제사 승인. 실패 시 머묾, 편지 내용은 보존 |
| 편지 도착 `LETTER_ARRIVED` | 어두운 창문 | 읽는 중 | 책방지기가 편지를 처음 엶 (REQ-052) |
| 읽는 중 `READING` | 촛불 켜짐 | 발송됨 | 책방지기가 책·답장·엽서·힌트를 채우고 발송 → 코드 자동 생성 (REQ-055) |
| 발송됨 `SHIPPED` | 촛불 꺼짐 + 우체통 불빛 + "책이 서점 문을 나섰습니다" | 언박싱됨 | 손님이 올바른 코드 입력 |
| 언박싱됨 `UNBOXED` | (언박싱된 책과 서가 메모 표시) | — | 종료 |

- 상태는 앞으로만 간다(D-010).
- 해지는 결제 완료된 진행 회차를 멈추지 않는다(Q-003). 결제 대기 회차는 해지 시 함께 취소된다.

## 6. 불변 규칙 (INV)

| ID | 규칙 | 근거 |
|---|---|---|
| INV-01 | 로그인 수단은 카카오·네이버 두 가지뿐이다. 아이디·비밀번호 가입은 없다 | REQ-021 |
| INV-02 | 장바구니·주문·구독·마이페이지·서가 메모는 로그인한 본인 것만 보이고 고칠 수 있다 | D-015 |
| INV-03 | 관리자 화면과 기능(책 관리, 편지 열람, 발송, 주소록)은 관리자만 쓸 수 있다 | D-017, REQ-056 |
| INV-04 | 결제가 확정되지 않은 주문·회차는 발송 상태로 넘어갈 수 없고, 회차 편지는 관리자 화면에 나타나지 않는다 | D-019 |
| INV-05 | 재고가 0인 책은 장바구니 담기·주문할 수 없고, 재고는 음수가 되지 않는다 | Q-006 |
| INV-06 | 같은 주문·회차의 결제 확정은 한 번만 처리된다 | REQ-018 |
| INV-07 | 언박싱 전에는 손님 화면·응답 어디에도 회차의 책 제목·표지·답장 편지·엽서 사진이 없고 힌트 문장만 있다 | REQ-038, REQ-039, D-011 |
| INV-08 | 언박싱 코드는 회차당 1개, 6자리 숫자, 발송 시 자동 생성되며 그 회차를 받은 손님 계정에서만 유효하다 | REQ-041, REQ-055, D-011 |
| INV-09 | 회차 상태(창가 등불)는 앞으로만 간다. 편지 첫 열람 시 촛불이 켜진다 | REQ-036, REQ-052, D-010 |
| INV-10 | 손님 화면에 택배사 송장번호·추적 정보를 보여주지 않는다 | REQ-034 |
| INV-11 | 별점·평점·공개 리뷰·댓글이 없다. 서가 메모는 본인만 본다 | REQ-043, REQ-044 |
| INV-12 | 서가 메모는 언박싱된 책에만, 책 1권당 1개, 100자 이하 | REQ-044, D-012 |
| INV-13 | 해지 흐름에 혜택 상실 경고·일시정지 제안·확인 팝업 등 중간 단계가 없다. 마지막 인사 → 작별 안부 입력(선택) → [구독을 마무리합니다] → 해지 완료 | REQ-045~048 |
| INV-14 | 한 손님은 구독 중일 때 결제 대기·편지 도착·읽는 중 상태인 회차를 동시에 1개만 가진다 | Q-001, Q-002, D-022 |
| INV-15 | 사용자 상호작용에 QR 코드 스캔이 없다 | REQ-040 |
