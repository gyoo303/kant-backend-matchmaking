## 4. 범위 통제 근거 (KANT-C3)
KANT-C3은 "로그인 등 필수 범위를 벗어난 작업으로 일정 차질이 없게 통제"를 요구한다. 팀 결정으로 로그인·결제·구독은 범위에 있으므로, **범위를 줄이지 않고 아래 방법으로 통제한다** (D-016).

1. **KANT 증빙 경로 우선**: KANT R1~R9가 모두 M1(1일차)에서 끝난다. 이후 마일스톤이 밀려도 평가 증빙은 이미 확보돼 있다.
2. **타임박스**: 마일스톤마다 끝나는 시점을 정한다. 넘치면 다음 마일스톤으로 가기 전에 사용자에게 보고하고 순서를 다시 정한다(범위를 몰래 빼지 않는다).
3. **외부 연동은 테스트 모드로 시작**: 결제는 PG 테스트 모드, 택배는 연동하지 않음 (ASM-021, Q-004).
4. **흐름 단순화로 분량 통제**: 자동결제 없음(Q-001), 회차 = 편지 1통(Q-002), 환불은 책방지기 처리(Q-005), 공통 작별 편지(D-014).
5. **근거 없는 기능은 Won't** (§2): 추가 요청은 decision-log에 카드로 올린 뒤에만 넣는다.
