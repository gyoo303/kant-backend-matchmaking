# 05. 사용자 스토리 & 기능 명세 (PM-US)

- 입력: PM-DOMAIN(용어·상태·INV), PM-SCOPE(마일스톤), PM-DEC(D-001~004 승인)
- 형식: `US-xx` 스토리 → 정상 흐름 → 예외·거부(`REJ-xx`) → 관련 INV. 수용 기준은 PM-AC의 `AC-xx-n`.
- 감성 요구는 관찰 가능한 행동으로 적었다. 시각 디자인(색·폰트·그림체)은 UX 몫이다.

## M1 쇼핑 기반

### US-01: 방문자로서, 이 책방이 어떤 곳인지 알기 위해, 메인에서 책방 소개와 4개 테마 서가를 보고 싶다.
- 정상 흐름
  1. `/`에 들어오면 Header, 책방 소개 글, 테마 4개(자연·식문화·생태·로컬) 입구, Footer가 보인다.
  2. 테마 입구마다 그 테마의 책 일부(ProductCard)가 보인다.
  3. 테마 입구를 누르면 그 테마로 걸러진 목록(US-02)으로 `<Link>` 이동한다.
- 예외·거부
  - REJ-01: 어떤 테마에 책이 0권이면 그 입구는 "준비 중인 서가입니다" 문구를 보이고 링크는 유지한다.
- 관련 INV: —

### US-02: 방문자로서, 마음에 드는 결의 책을 찾기 위해, 책 목록을 테마별로 보고 싶다.
- 정상 흐름
  1. `/products`에서 전체 책이 ProductCard 그리드로 보인다(표지·제목·저자·가격·품절 표시).
  2. 테마를 고르면 그 테마 책만 보인다. 선택한 테마 이름과 짧은 소개가 목록 위에 보인다.
  3. 카드를 누르면 상세(US-03)로 `<Link>` 이동한다.
- 예외·거부
  - REJ-02: 없는 테마 값으로 들어오면 전체 목록과 "없는 테마입니다" 안내를 보인다(크래시 없음).
  - REJ-03: 책 데이터를 못 가져오면 "책을 불러오지 못했습니다" 문구를 보인다.
- 관련 INV: INV-05(품절 표시)

### US-03: 방문자로서, 책방지기가 왜 이 책을 권하는지 알기 위해, 상세 화면 맨 위에서 책방지기 노트를 읽고 싶다.
- 정상 흐름
  1. `/products/[id]`에서 책방지기 노트가 화면 최상단, 본문보다 큰 글씨로 보인다.
  2. 그 아래 표지, 제목, 저자, 테마, 가격, [장바구니 담기], 출판사 소개 순으로 보인다.
- 예외·거부
  - REJ-04: 없는 ID → "상품을 찾을 수 없습니다" + 목록으로 가는 링크(KANT-C14).
  - REJ-05: 책방지기 노트가 비어 있으면 출판사 소개가 맨 위로 온다.
  - REJ-06: 품절이면 [장바구니 담기] 대신 "품절" 표시, 누를 수 없다.
- 관련 INV: INV-05

### US-04: 방문자로서, 밤에 태블릿·노트북으로도 편하게 읽기 위해, 어떤 화면 크기에서도 글과 사진이 깨지지 않기를 바란다.
- 정상 흐름: 360·768·1280px에서 모든 화면이 가로 스크롤 없이, 이미지 비율 유지로 보인다(NFR-02).
- 예외·거부: REJ-07: 표지 이미지를 못 불러오면 같은 비율의 대체 그림을 보인다.
- 관련 INV: —

## M2 회원·관리자 기반

### US-05: 손님으로서, 가입 피로 없이 시작하기 위해, 카카오나 네이버로 로그인·로그아웃하고 싶다.
- 정상 흐름
  1. Header의 [로그인] → 로그인 화면에 [카카오로 시작하기], [네이버로 시작하기] 두 버튼만 보인다.
  2. 제공자 동의 후 돌아오면 처음 로그인이면 회원이 자동 생성되고, 원래 가려던 화면으로 돌아간다.
  3. Header에 [마이페이지], [로그아웃]이 보인다.
- 예외·거부
  - REJ-08: 제공자 화면에서 취소·실패 → 로그인 화면에 "로그인을 마치지 못했어요. 다시 시도해 주세요".
  - REJ-09: 비로그인으로 보호 화면(장바구니·주문·편지·마이페이지) 접근 → 로그인 화면으로 이동, 로그인 후 원래 화면 복귀.
- 관련 INV: INV-01, INV-02

### US-06: 책방지기로서, 서가를 직접 꾸리기 위해, 책을 등록·수정하고 재고를 관리하고 싶다.
- 정상 흐름
  1. 관리자 메뉴 → 책 관리 목록(제목·테마·가격·재고).
  2. [새 책] → 제목·저자·출판사·가격·표지 이미지·출판사 소개·테마·책방지기 노트·재고 입력 → 저장 → 목록·상세에 반영.
  3. 기존 책 수정 → 저장 → 반영. 재고를 0으로 두면 손님 화면에 품절.
- 예외·거부
  - REJ-10: 필수 항목(제목·저자·가격·표지·설명·테마·재고) 누락, 가격·재고 음수 → 저장 안 됨, 항목 옆 안내.
  - REJ-11: 관리자가 아닌 사람이 접근 → 접근 거부(NFR-06).
- 관련 INV: INV-03, INV-05
- 비고: 책 삭제는 범위 밖(의뢰서·답변 근거 없음). 판매 중지가 필요하면 재고 0으로 처리.

## M3 구매

### US-07: 손님으로서, 고른 책을 한 번에 사기 위해, 장바구니에 담고 수량을 고치고 빼고 싶다.
- 정상 흐름
  1. 상세에서 [장바구니 담기] → "장바구니에 담았어요" 안내, Header 장바구니 수 갱신.
  2. `/cart`에서 책별 수량 변경·삭제, 합계 금액 표시.
- 예외·거부
  - REJ-12: 비로그인 담기 → 로그인 후 그 상세로 복귀(REJ-09).
  - REJ-13: 재고보다 많은 수량 → 재고까지만 허용, "남은 책이 N권이에요".
  - REJ-14: 담아 둔 책이 그 사이 품절 → 장바구니에서 품절 표시, 주문에서 제외해야 진행.
- 관련 INV: INV-02, INV-05

### US-08: 손님으로서, 책을 받기 위해, 배송지를 넣고 카드·간편결제로 주문하고 싶다.
- 정상 흐름
  1. 장바구니 [주문하기] → 배송지(받는 사람·주소·연락처) 입력, 저장된 기본 배송지가 있으면 미리 채움(D-004).
  2. 결제 수단(카드·간편결제) 선택 → 결제(테스트 모드, D-002).
  3. 승인 → 주문 "결제 완료", 재고 차감, 장바구니 비움, 주문 완료 화면.
- 예외·거부
  - REJ-15: 배송지 필수 항목 누락·연락처 형식 오류 → 진행 불가, 안내.
  - REJ-16: 결제 실패·취소 → 주문 "결제 대기" 유지, 장바구니 유지, "결제가 완료되지 않았어요" + 다시 결제(D-019).
  - REJ-17: 결제 직전 재고 부족 → 결제 진행 안 함, 장바구니로 돌아가 안내.
  - REJ-18: 같은 결제 승인이 두 번 도착 → 한 번만 반영(INV-06).
- 관련 INV: INV-04, INV-05, INV-06

### US-09: 손님으로서, 책이 어디쯤 왔는지 알기 위해, 주문 내역과 짧은 상태 문구를 보고 싶다.
- 정상 흐름: 마이페이지 주문 내역에 주문일·책·금액·상태(결제 대기 / 준비 중 / 발송됨 / 취소됨)가 보인다.
- 예외·거부
  - REJ-19: 다른 사람의 주문 ID로 접근 → "주문을 찾을 수 없습니다"(존재 여부 노출 안 함).
  - REJ-20: 결제 대기 주문은 [주문 취소] 가능, 결제 완료 이후는 취소 버튼 없음(환불은 수동, W-09).
- 관련 INV: INV-02, INV-10

### US-10: 책방지기로서, 손님에게 발송 사실을 알리기 위해, 일반 주문을 발송 처리하고 싶다.
- 정상 흐름: 관리자 일반 주문 목록(결제 완료 건) → [발송 처리] → 손님 화면 "발송됨".
- 예외·거부
  - REJ-21: 결제 대기·취소 주문은 발송 처리 불가.
- 관련 INV: INV-03, INV-04

## M4 편지 구독

### US-11: 손님으로서, 책방지기에게 내 마음을 전하기 위해, 편지지에 편지를 써서 우체통에 넣고 이번 회차를 결제하고 싶다.
- 정상 흐름
  1. `/letter`에 편지지 화면(자유 글 입력, 체크박스·설문 없음)과 하단 [우체통에 편지 넣기].
  2. 누르면 배송지 확인(D-004) → 회차 결제(D-002) → 승인.
  3. 봉투가 닫혀 우체통으로 들어가는 전환이 재생되고(NFR-08), 끝나면 "편지가 책방에 도착했어요" 문구와 마이페이지 링크.
  4. 첫 회차면 구독 시작(구독 중), 회차 상태 "편지 도착".
- 예외·거부
  - REJ-22: 빈 편지·최소 글자 미만(10자)·최대 초과(2,000자) → 넣을 수 없음, 안내.
  - REJ-23: 발송 전 진행 회차가 이미 있음 → 편지지 대신 "지난 편지의 책이 아직 준비 중이에요" + 마이페이지 링크(INV-14).
  - REJ-24: 결제 실패·취소 → 회차 "결제 대기", 쓴 편지 보존, 다시 결제 가능. 연출은 재생되지 않음.
- 관련 INV: INV-04, INV-06, INV-14

### US-12: 손님으로서, 책방지기가 내 편지를 읽고 있는지 느끼기 위해, 마이페이지에서 서점 창가 그림으로 진행 상태를 보고 싶다.
- 정상 흐름: 마이페이지에 현재 회차의 창가 그림이 상태별로 보인다.
  - 편지 도착 → 어두운 창문
  - 읽는 중 → 창가 촛불(스탠드) 켜짐
  - 발송됨 → 촛불 꺼짐, 창가 옆 우체통 불빛, "책이 서점 문을 나섰습니다"
  - 언박싱됨 또는 회차 없음 → 창가 그림 대신 "새 편지 쓰기" 입구와 나의 서가
- 예외·거부
  - REJ-25: 결제 대기 회차 → 창가 대신 "결제를 마치면 편지가 책방으로 떠나요" + 다시 결제.
- 관련 INV: INV-09, INV-10

### US-13: 책방지기로서, 손님이 내가 읽고 있음을 느끼게 하기 위해, 도착한 편지를 열고 싶다.
- 정상 흐름
  1. 관리자 서재 작업 화면 목록에 "편지 도착"·"읽는 중" 회차가 오래된 순으로 보인다.
  2. 회차를 열면 한 화면 세로 순서로 ① 편지 ② 책 매칭·답장·엽서 ③ 힌트·발송 영역이 보인다(REQ-051).
  3. 처음 연 순간 회차가 "읽는 중"이 되고 손님 화면 촛불이 켜진다.
- 예외·거부
  - REJ-26: 이미 "읽는 중"인 회차를 다시 열어도 상태는 그대로.
  - REJ-27: 결제 대기 회차는 목록에 없다(INV-04).
- 관련 INV: INV-03, INV-04, INV-09

### US-14: 책방지기로서, 손님에게 맞는 책을 보내기 위해, 책을 매칭하고 답장·엽서·힌트를 넣어 발송하고 싶다.
- 정상 흐름
  1. ② 영역에서 서점 책을 제목·저자로 검색해 1권 고른다(재고 있는 책만).
  2. 답장 편지를 쓰고 엽서 사진 1장을 올린다.
  3. ③ 영역에서 힌트 문장을 쓰고 [발송] → 6자리 코드가 자동 생성되어 화면에 크게 표시(손글씨 카드에 옮겨 적기용), 재고 1 차감, 회차 "발송됨".
- 예외·거부
  - REJ-28: 책·답장·힌트 중 하나라도 비면 발송 불가, 빈 항목 안내. 엽서 사진은 선택.
  - REJ-29: 엽서 사진이 이미지가 아니거나 10MB 초과 → 올라가지 않음, 안내.

### US-15: 손님으로서, 상자를 열기 전까지 설렘을 지키기 위해, 발송된 책을 실루엣과 힌트 문장으로만 보고 싶다.

### US-16: 손님으로서, 상자 속 카드의 코드로 책을 확인하기 위해, 6자리 코드를 직접 입력해 언박싱하고 싶다.
