# 06. 수용 기준 (PM-AC)

- 입력: PM-US. 번호 `AC-<US번호>-n`, `NFR-xx`는 이후 모든 단계가 그대로 쓴다.
- 🅴 = 예외·거부 시나리오 AC. 모든 US에 1개 이상.

## 1. 기능 AC

### US-01 메인
| AC | Given | When | Then |
|---|---|---|---|
| AC-01-1 | 테마별 책이 1권 이상 있다 | 방문자가 `/`에 들어온다 | Header, 책방 소개, 테마 4개(자연·식문화·생태·로컬) 입구, 테마별 ProductCard, Footer가 보인다 |
| AC-01-2 | 메인이 열려 있다 | 테마 입구를 누른다 | 전체 새로고침 없이 그 테마로 걸러진 `/products`로 이동한다 |
| AC-01-3 🅴 | 어떤 테마의 책이 0권이다 | 메인에 들어온다 | 그 입구에 "준비 중인 서가입니다"가 보이고 오류가 없다 |

### US-02 목록
| AC | Given | When | Then |
|---|---|---|---|
| AC-02-1 | 책이 6권 이상 있다 | `/products`에 들어온다 | 모든 책이 ProductCard(표지·제목·저자·가격)로 같은 간격 그리드에 보인다 |
| AC-02-2 | 목록이 열려 있다 | "생태" 테마를 고른다 | 생태 책만 보이고 테마 이름·소개가 위에 보인다 |
| AC-02-3 | 재고 0인 책이 있다 | 목록을 본다 | 그 카드에 "품절"이 보인다 |
| AC-02-4 | 목록이 열려 있다 | 카드를 누른다 | 전체 새로고침 없이 그 책의 `/products/[id]`로 이동한다 |
| AC-02-5 🅴 | — | 없는 테마 값으로 목록에 들어온다 | 전체 목록과 "없는 테마입니다"가 보이고 크래시가 없다 |

### US-03 상세
| AC | Given | When | Then |
|---|---|---|---|
| AC-03-1 | 책방지기 노트가 있는 책 | 상세에 들어온다 | 노트가 표지·제목보다 위, 본문보다 큰 글씨로 보이고, 그 아래 표지·제목·저자·테마·가격·[장바구니 담기]·출판사 소개가 보인다 |
| AC-03-2 | 노트가 없는 책 | 상세에 들어온다 | 출판사 소개가 맨 위에 보인다 |
| AC-03-3 🅴 | — | `/products/없는-id`에 들어온다 | "상품을 찾을 수 없습니다"와 목록 링크가 보이고 크래시가 없다 |
| AC-03-4 🅴 | 재고 0인 책 | 상세에 들어온다 | [장바구니 담기] 대신 비활성 "품절"이 보인다 |

### US-04 반응형
| AC | Given | When | Then |
|---|---|---|---|
| AC-04-1 | 메인·목록·상세 | 화면 폭 360·768·1280px로 본다 | NFR-02를 만족한다 |
| AC-04-2 🅴 | 표지 이미지 URL이 깨졌다 | 카드·상세를 본다 | 같은 비율의 대체 그림이 보이고 레이아웃이 밀리지 않는다 |

### US-05 로그인
| AC | Given | When | Then |
|---|---|---|---|
| AC-05-1 | 비로그인 | 로그인 화면을 연다 | 카카오·네이버 버튼 두 개만 있고 아이디·비밀번호 입력란이 없다 |
| AC-05-2 | 처음 오는 손님 | 카카오(또는 네이버)로 동의를 마친다 | 회원이 생기고 원래 화면으로 돌아오며 Header에 [마이페이지]·[로그아웃]이 보인다 |
| AC-05-3 | 로그인 상태 | [로그아웃]을 누른다 | 비로그인 Header로 바뀌고 보호 화면 접근 시 로그인 화면으로 간다 |
| AC-05-4 🅴 | 비로그인 | `/cart`, `/letter`, `/mypage`에 들어온다 | 로그인 화면으로 이동하고, 로그인 후 원래 화면으로 돌아온다 |
| AC-05-5 🅴 | — | 제공자 화면에서 취소한다 | "로그인을 마치지 못했어요. 다시 시도해 주세요"가 보인다 |

### US-06 책 관리
| AC | Given | When | Then |
|---|---|---|---|
| AC-06-1 | 관리자 로그인 | 필수 항목을 채워 새 책을 저장한다 | 책 관리 목록·손님 목록·상세에 나타난다 |
| AC-06-2 | 관리자, 재고 3인 책 | 재고를 0으로 저장한다 | 손님 화면에 "품절"이 보인다 |
| AC-06-3 🅴 | 관리자 | 가격 -1 또는 제목 빈칸으로 저장한다 | 저장되지 않고 그 항목 옆에 안내가 보인다 |
| AC-06-4 🅴 | 일반 회원 | 책 관리 화면·기능에 접근한다 | NFR-06대로 거부된다 |

### US-07 장바구니
| AC | Given | When | Then |
|---|---|---|---|
| AC-07-1 | 로그인, 재고 있는 책 | [장바구니 담기] | 안내가 보이고 Header 장바구니 수가 1 늘어난다 |
| AC-07-2 | 장바구니에 책 2종 | 수량을 바꾸거나 1종을 뺀다 | 합계 금액이 즉시 다시 계산된다 |
| AC-07-3 🅴 | 재고 2인 책 | 수량을 3으로 올린다 | 2까지만 되고 "남은 책이 2권이에요"가 보인다 |
| AC-07-4 🅴 | 담아 둔 책이 품절됐다 | 장바구니를 연다 | 그 책에 "품절"이 보이고 빼기 전에는 [주문하기]가 비활성이다 |

### US-08 주문·결제
| AC | Given | When | Then |
|---|---|---|---|
| AC-08-1 | 장바구니에 책, 기본 배송지 저장됨 | [주문하기] | 배송지가 미리 채워져 있다 |
| AC-08-2 | 배송지 입력 완료 | 테스트 결제가 승인된다 | 주문 "결제 완료", 재고가 수량만큼 줄고, 장바구니가 비고, 주문 완료 화면이 보인다 |
| AC-08-3 🅴 | 결제 화면 | 결제를 취소·실패한다 | 주문 "결제 대기", 장바구니 유지, "결제가 완료되지 않았어요"와 다시 결제 버튼이 보인다 |
| AC-08-4 🅴 | 배송지 연락처 빈칸 | 결제로 진행한다 | 진행되지 않고 안내가 보인다 |
| AC-08-5 🅴 | 결제 직전 재고 부족 | 결제를 시작한다 | 결제가 시작되지 않고 장바구니로 돌아가 안내가 보인다 |
| AC-08-6 🅴 | 결제 완료된 주문 | 같은 승인 통지가 한 번 더 온다 | 재고·주문 상태가 한 번만 반영된다 |

| AC-09-2 | 결제 대기 주문 | [주문 취소] | "취소됨"이 된다 |

### US-11 손편지·회차 결제
| AC | Given | When | Then |
|---|---|---|---|
| AC-11-1 | 진행 회차 없는 로그인 손님 | `/letter`를 연다 | 자유 글 편지지와 [우체통에 편지 넣기]가 있고 체크박스·객관식이 없다 |
| AC-11-2 | 편지 10자 이상 | [우체통에 편지 넣기] → 배송지 확인 → 결제 승인 | 봉투·우체통 전환(NFR-08) 후 "편지가 책방에 도착했어요"가 보이고 회차가 "편지 도착", 첫 회차면 구독 "구독 중" |
| AC-11-3 🅴 | 편지 5자 | 넣으려 한다 | 넣어지지 않고 최소 글자 안내가 보인다 |
| AC-11-4 🅴 | 발송 전 진행 회차가 있다 | `/letter`를 연다 | 편지지 대신 "지난 편지의 책이 아직 준비 중이에요"가 보인다 |
| AC-11-5 🅴 | 편지 작성 후 결제 화면 | 결제를 취소한다 | 회차 "결제 대기", 편지 내용 보존, 연출 없음, 다시 결제 가능 |

## 2. 비기능 NFR (정량)

| NFR | 영역 | 기준 | 확인 방법 |
|---|---|---|---|
| NFR-01 | 성능 | 메인·목록·상세: 모바일(Lighthouse 모바일 기본 조건) LCP ≤ 2.5s, CLS ≤ 0.1 | Lighthouse |
| NFR-02 | 반응형 | 360·768·1280px 모든 화면에서 가로 스크롤 0, 글자 겹침 0, 이미지는 고정 비율 + object-cover | 폭별 스크린샷 |
