# 06. 수용 기준 (PM-AC)

- 입력: PM-US(US-01~21, REJ-01~53), PM-DOMAIN(INV), PM-DEC
- 기능 AC: `AC-<US번호>-n` Given/When/Then. 스토리마다 예외 AC ≥ 1 (⚠ 표시).
- 비기능: `NFR-xx`, 정량 기준만. QA는 이 ID를 그대로 테스트 케이스 ID로 쓴다.

## 1. 기능 AC

### M1 쇼핑 기반
**US-01 메인**
- AC-01-1: Given 방문자, When `/`에 들어오면, Then Header·책방 소개·테마 4개 카드·새로 들어온 책 ProductCard 1개 이상(재고 있는 책 중 최근 등록 순 최대 4권, D-035)·Footer가 보이고, Header에 "편지 띄우기" 링크가 있다 (D-042).
- AC-01-2: Given 메인, When 테마 카드 "생태"를 누르면, Then 전체 새로고침 없이 생태 테마 목록으로 이동한다 (NFR-14).
- AC-01-3: Given 메인, Then Footer에 책방 이름이 있고, 사업자 정보·환불 규정·개인정보 처리방침 영역은 없다 (D-021).
- ⚠ AC-01-4: Given 책 데이터 조회 실패, When 메인에 들어오면, Then 소개·테마 영역은 보이고 새로 들어온 책 영역에 "책을 불러오지 못했어요"가 보인다 (REJ-01).

**US-02 테마 서가**
- AC-02-1: Given 책 6권 이상, When `/products`에 들어오면, Then 전체 책이 카드로 모두 보이고 각 카드에 표지·제목·저자·가격·테마가 있다.
- AC-02-2: Given 목록, When "식문화"를 고르면, Then 식문화 책만 보이고 주소에 선택한 테마가 남으며, 뒤로 가기로 이전 선택으로 돌아간다.
- AC-02-3: Given 재고 0인 책, Then 그 카드에 "품절"이 표시된다.
- ⚠ AC-02-4: Given 책이 없는 테마, When 고르면, Then "이 서가는 아직 비어 있어요"와 다른 테마 링크가 보인다 (REJ-02).
- ⚠ AC-02-5: Given 주소의 테마 값이 `abc`, When 들어오면, Then 오류 없이 전체 목록이 보인다 (REJ-03).

**US-03 책 상세**
- AC-03-1: Given 존재하는 책 ID, When `/products/[id]`에 들어오면, Then 그 ID의 책 정보가 보이고, 책방지기 노트가 다른 본문보다 위에 보인다 (INV-02).
- AC-03-2: Given 출판사 소개가 없는 책, Then 출판사 소개 영역이 나오지 않는다.
- AC-03-3: Given 비회원, When [장바구니 담기]를 누르면, Then 로그인 화면으로 가고, 로그인 후 같은 상세로 돌아온다.
- ⚠ AC-03-4: Given 없는 ID, When 상세에 들어오면, Then 화면이 멈추지 않고 "상품을 찾을 수 없습니다"와 목록 링크가 보인다 (REJ-04, KANT-C14).
- ⚠ AC-03-5: Given 재고 0인 책, Then [장바구니 담기]가 비활성이고 "품절"이 보인다 (REJ-05).

**US-04 반응형**
- AC-04-1: NFR-02, NFR-03을 모든 M1 화면이 만족한다.
- ⚠ AC-04-2: Given 표지 이미지 주소가 깨진 책, Then 대체 표지가 같은 비율로 보인다 (REJ-06).

### M2 회원·관리자 기반
**US-05 로그인·마이페이지**
- AC-05-1: Given 로그인 화면, Then 로그인 수단은 [카카오로 시작하기], [네이버로 시작하기] 2개뿐이고 아이디·비밀번호 칸이 없다 (INV-03).
- AC-05-2: Given 처음 온 사람, When 카카오(또는 네이버) 로그인을 마치면, Then 추가 입력 없이 회원이 되고 로그인 전 화면으로 돌아온다.
- AC-05-3: Given 회원, When 마이페이지에 들어오면, Then 주문 현황·창가·나의 서가·기본 배송지·로그아웃·탈퇴 메뉴가 보이고, "창가"는 창가 화면(SCR-15)으로 간다 (D-042).
- AC-05-4: Given 발송 전 결제 완료 주문·결제 확정된 진행 중 회차가 없는 회원, When 탈퇴하면, Then PM-DOMAIN §7대로 기본 배송지·장바구니·손편지·답장·엽서·서가 메모·작별 안부가 지워지고, 거래 기록은 회원 연결 없이 남으며, 로그아웃된다.
- AC-05-8: Given 결제 대기 주문 1건과 결제 대기 회차 1건이 있는 회원, When 탈퇴하면, Then 탈퇴되고 두 건 모두 취소 상태가 된다.
- ⚠ AC-05-5: Given 소셜 로그인 취소, Then 로그인 화면에 "로그인을 마치지 못했어요" 안내가 보인다 (REJ-07).
- ⚠ AC-05-6: Given 비회원, When `/cart`·주문·편지·마이페이지 주소로 들어오면, Then 로그인 화면으로 가고 로그인 후 원래 주소로 돌아온다 (REJ-08).
- ⚠ AC-05-7: Given 읽는 중 회차가 있는 회원, When 탈퇴를 누르면, Then 탈퇴되지 않고 이유가 보인다 (REJ-09).
- ⚠ AC-05-9: Given 주문 접수(`paid`) 주문이 있는 회원, When 탈퇴를 누르면, Then 탈퇴되지 않고 이유가 보인다 (REJ-09).

**US-06 책 관리**
- AC-06-1: Given 책방지기, When 필수 항목을 모두 넣고 새 책을 저장하면, Then 목록·상세에 그 책이 보인다.
- AC-06-2: Given 책방지기, When 재고를 0으로 수정하면, Then 목록·상세에 "품절"이 표시되고 담기가 막힌다.
- AC-06-3: Given 책 관리 화면, Then 삭제 버튼이 없다 (D-023).
- ⚠ AC-06-4: Given 가격 `-1000` 또는 재고 `1.5`, When 저장하면, Then 저장되지 않고 해당 칸에 이유가 보인다 (REJ-10).
- ⚠ AC-06-5: Given 일반 회원·비회원, When 관리자 화면 주소로 들어오면, Then 관리자 화면이 보이지 않는다 (REJ-11, NFR-06).

### M3 구매
**US-07 장바구니**
- AC-07-1: Given 회원, When 상세에서 담으면, Then "장바구니에 담았어요"가 보이고 Header 개수가 1 늘어난다.
- AC-07-2: Given 장바구니, When 수량을 2에서 3으로 바꾸면, Then 합계 금액이 바로 바뀐다.
- AC-07-3: Given 이미 담은 책, When 다시 담으면, Then 줄이 늘지 않고 수량이 1 늘어난다 (REJ-14).
- ⚠ AC-07-4: Given 재고 2권, When 수량 3을 넣으면, Then 2로 맞춰지고 "남은 책은 2권이에요"가 보인다 (REJ-12).
- ⚠ AC-07-5: Given 담은 뒤 품절된 책, Then 장바구니에 "품절"로 보이고 주문 대상에서 빠진다 (REJ-13).

**US-08 주문·결제**
- AC-08-1: Given 장바구니에 책이 있는 회원, When 배송지를 넣고 테스트 결제를 마치면, Then 주문이 "주문 접수"가 되고, 재고가 수량만큼 줄고, 장바구니에서 빠지고, 주문 번호가 보인다.
- AC-08-2: Given 첫 주문에서 배송지를 넣은 회원, When 다음 주문서를 열면, Then 그 배송지가 미리 채워져 있다.
- AC-08-3: Given 주문 후 기본 배송지를 바꾼 회원, Then 이미 한 주문의 배송지는 바뀌지 않는다 (D-004).
- ⚠ AC-08-4: Given 결제 창을 닫음, Then 주문은 결제 대기, 장바구니는 그대로, [다시 결제하기]가 보인다 (REJ-15).
- ⚠ AC-08-5: Given 결제 확정 직전 재고 부족, Then 주문은 확정되지 않고 결제는 취소되며 품절 안내가 보인다 (REJ-16).
- ⚠ AC-08-6: Given 같은 결제 확정 신호 2회, Then 재고 감소·상태 변경은 1회만 일어난다 (REJ-17, NFR-07).
- ⚠ AC-08-7: Given 받는 사람·연락처·주소 중 빈칸, Then 결제 창이 열리지 않는다 (REJ-18).
- ⚠ AC-08-8: Given 합계 45,000원 주문, When 결제 대행사 승인 금액이 1,000원으로 오면, Then 주문은 확정되지 않고 결제가 취소되며 재고는 그대로다 (REJ-56, NFR-19).

**US-09 주문 현황·취소 요청**
- AC-09-1: Given 주문 접수 상태 주문, Then 마이페이지에 "주문 접수 → 발송됨" 2단계 중 1단계가 표시된다.
- AC-09-2: Given 주문 접수 주문, When [취소 요청]을 누르면, Then "취소 요청을 책방지기에게 전했어요"가 보이고 책방지기 주문 화면에 취소 요청으로 보인다.
- ⚠ AC-09-3: Given 발송된 주문, Then [취소 요청] 버튼이 없다 (REJ-19).
- ⚠ AC-09-4: Given 다른 회원의 주문 ID, When 그 주소로 들어오면, Then 주문 내용이 보이지 않는다 (REJ-20).
- AC-09-5: Given 취소 요청 주문, When 회원이 [취소 요청 철회]를 누르면, Then 주문은 "주문 접수"로 돌아가고 책방지기 화면에서 발송할 수 있다.
- AC-09-6: Given 책방지기가 거절한 주문, Then 회원 화면에 "책방지기가 취소 요청을 받지 않았어요. 책은 그대로 보내드려요"가 보인다.
- ⚠ AC-09-7: Given 이미 환불 완료된 주문, When 회원이 철회를 시도하면, Then 상태는 "환불 완료" 그대로이고 현재 상태가 안내된다 (REJ-58).

**US-10 발송·환불 처리**
- AC-10-1: Given 주문 접수 주문, When 책방지기가 [발송 완료]를 누르면, Then 회원 화면에 "발송됨"이 보인다.
- AC-10-2: Given 취소 요청 주문, When [환불]을 누르면, Then 테스트 결제가 환불되고, 주문은 "환불 완료", 재고는 원래대로 돌아온다.
- ⚠ AC-10-3: Given 결제 대행사 환불 실패, Then 주문 상태는 그대로이고 "환불하지 못했어요" 안내가 보인다 (REJ-21).
- ⚠ AC-10-4: Given 취소 요청 주문, Then [발송 완료]가 막힌다 (REJ-22).
- ⚠ AC-10-5: Given [환불] 2회 연속 클릭, Then 환불·재고 복구는 1회만 (REJ-23, NFR-07).
- AC-10-6: Given 취소 요청 주문, When 책방지기가 [취소 거절]을 누르면, Then 주문은 "주문 접수"로 돌아가고 환불은 일어나지 않으며 [발송 완료]를 누를 수 있다.

### M4 편지 구독
**US-11 편지 띄우기**
- AC-11-1: Given 진행 중 회차가 없는 회원, When 편지 화면에 들어오면, Then 체크박스·설문 없이 편지지 한 장과 회차 금액 "30,000원"·배송지 확인이 보이고, 결제 금액도 30,000원이다 (D-003).
- AC-11-2: Given 10자 이상 편지, When [우체통에 편지 넣기]를 누르면, Then 봉투 닫힘 전환(NFR-10)이 재생된 뒤 결제로 이어지고, 결제가 확정된 뒤에만 봉투가 우체통에 들어가는 전환(NFR-10)이 재생된다 (D-041).
- AC-11-3: Given 첫 편지 결제 확정, Then 구독이 진행 중이 되고 회차는 "편지 도착", 마이페이지 창가는 어두운 창문이다.
- ⚠ AC-11-4: Given 편지 도착 또는 읽는 중 회차가 있는 회원, When 편지 화면에 들어오면, Then 편지지 대신 "지금 책방지기가 편지를 준비하고 있어요"와 창가 링크가 보인다 (REJ-24, INV-12).
- ⚠ AC-11-8: Given 결제 대기 회차가 있는 회원, When 편지 화면에 들어오면, Then 새 편지지 대신 그 편지 내용과 "아직 결제가 끝나지 않았어요", [다시 결제하기]·[편지 거두기]가 보인다 (REJ-54).
- ⚠ AC-11-9: Given 회원 B, When 회원 A의 손편지를 어떤 주소·데이터 요청으로든 요청하면, Then 받을 수 없다 (REJ-55, INV-19, NFR-09).
- ⚠ AC-11-10: Given 회차 결제, When 결제 대행사 승인 금액이 30,000원이 아니면, Then 회차는 편지 도착으로 바뀌지 않고 결제가 취소된다 (REJ-57, NFR-19).
- ⚠ AC-11-5: Given 9자 또는 2,001자, Then [우체통에 편지 넣기]가 비활성이고 글자 수가 보인다 (REJ-25).
- ⚠ AC-11-6: Given 결제 창 닫음, Then 봉투가 우체통에 들어가는 전환은 재생되지 않고(D-041), 편지 내용이 남아 있고 [다시 결제하기]·[편지 거두기]가 보이며, 이 편지는 서재 작업 화면에 없다 (REJ-26, INV-18).
- ⚠ AC-11-7: Given 동작 줄이기 설정, Then 애니메이션 없이 정지 그림과 문구가 보인다 (REJ-27).

**US-12 창가 등불**
- AC-12-1: Given 회차 "편지 도착", When 회원이 창가에 들어오면(첫 결제 직후가 아니어도), Then 창문이 어둡고 "편지가 서점에 도착했어요"가 보인다.
- AC-12-2: Given 회차 "읽는 중", Then 창가 촛불이 켜져 있고 "책방지기가 당신의 편지를 읽고 있어요"가 보인다.
- AC-12-3: Given 회차 "발송됨", Then 촛불이 꺼지고 우체통 불빛과 "책이 서점 문을 나섰습니다"가 보인다.
- AC-12-4: Given 어떤 상태든, Then 택배사 이름·운송장 번호·배송 단계 숫자는 보이지 않는다 (REQ-034).
- ⚠ AC-12-5: Given 진행 중 회차 없음, Then 빈 창가와 "지금 진행 중인 편지가 없어요", [편지 띄우기]가 보인다 (REJ-28).
- ⚠ AC-12-6: Given 책방지기가 편지를 연 뒤, When 회원이 마이페이지에 다시 들어오면, Then 촛불이 켜져 있다 (REJ-29, NFR-17).
- AC-12-7: Given 취소 요청 표시가 있는 읽는 중 회차, Then 촛불은 켜진 그대로이고 "취소 요청 중" 문구와 [취소 요청 철회]가 보인다.

**US-13 편지 읽기**
- AC-13-1: Given 서재 작업 화면, Then 편지 읽기 → 책 매칭·답장·엽서 → 힌트·발송이 한 열에 위에서 아래 순서로 있고 좌우 분할이 없다 (NFR-13).
- AC-13-2: Given "편지 도착" 회차, When 책방지기가 처음 열면, Then 회차가 "읽는 중"이 된다.
- AC-13-3: Given "읽는 중" 회차, When 다시 열면, Then 상태가 바뀌지 않는다 (INV-09).
- ⚠ AC-13-4: Given 결제 대기 회차, Then 서재 작업 화면 목록에 없다 (REJ-30).
- ⚠ AC-13-5: Given 일반 회원, When 서재 작업 화면 주소로 들어오면, Then 보이지 않는다 (REJ-31, NFR-06).

**US-14 매칭·답장·엽서**
- AC-14-1: Given 읽는 중 회차, When 제목으로 책을 검색해 고르고 답장과 엽서 사진 1장을 넣으면, Then 회차에 저장되고 나갔다 와도 남아 있다.
- ⚠ AC-14-2: Given 재고 0인 책, Then 검색 결과에 "품절"로 보이고 고를 수 없다 (REJ-32).
- ⚠ AC-14-3: Given 11MB 이미지 또는 PDF, Then 올라가지 않고 이유가 보인다 (REJ-33).

**US-15 힌트·발송**
- AC-15-1: Given 책·답장·힌트가 모두 있음, When [발송]을 누르면, Then 6자리 숫자 코드가 보이고, 회차는 "발송됨", 책 재고가 1 줄고, 회원 창가는 우체통 불빛이 된다.
- AC-15-2: Given 발송한 회차, When 나중에 관리자 화면에서 열면, Then 같은 코드를 다시 볼 수 있다.
- ⚠ AC-15-3: Given 힌트 없음, Then [발송]이 비활성이고 빠진 항목이 표시된다 (REJ-34).
- ⚠ AC-15-4: Given [발송] 2회 연속 클릭, Then 코드는 1개, 재고 감소 1회 (REJ-35, NFR-07).
- ⚠ AC-15-5: Given 매칭한 책 재고가 발송 직전 0, Then 발송되지 않고 다른 책을 고르라는 안내가 보인다 (REJ-36).

**US-16 언박싱**
- AC-16-1: Given 발송된 회차, Then 회원 화면에 실루엣·힌트·코드 입력 칸만 보이고 제목·표지·답장·엽서는 없다 (INV-07).
- AC-16-2: Given 맞는 코드, When 입력하고 [열기]를 누르면, Then 공개 전환(NFR-10) 뒤 표지·제목·답장·엽서가 보이고 회차는 "언박싱됨"이다.
- ⚠ AC-16-3: Given 틀린 코드, Then "코드가 맞지 않아요…"가 보이고 다시 입력할 수 있다 (횟수 제한 없음, REJ-37).
- ⚠ AC-16-4: Given 회원 A의 코드를 회원 B가 B의 회차에 입력, Then 틀린 코드와 같은 안내만 보인다 (REJ-38).
- ⚠ AC-16-5: Given 5자리 또는 문자 입력, Then [열기]가 비활성이다 (REJ-39).
- ⚠ AC-16-6: Given 언박싱 전 회차, When 회원이 받는 화면 소스·데이터 응답을 살펴보면, Then 그 회차 책의 제목·표지 주소·답장·엽서 주소가 없다 (REJ-40, NFR-08).
- ⚠ AC-16-7: Given 동작 줄이기 설정, When 맞는 코드를 입력하면, Then 전환 없이 바로 공개된다 (REJ-41, NFR-10).

**US-17 서가 메모**
- AC-17-1: Given 언박싱된 책, When 100자 이하 메모를 저장하면, Then 책 아래에 메모와 저장 날짜가 보인다.
- AC-17-2: Given 저장된 메모, When 수정·삭제하면, Then 반영되고 날짜는 마지막 저장일이다.
- AC-17-3: Given 나의 서가, Then 별점·공개·공유·댓글 요소가 없다 (INV-11).
- ⚠ AC-17-4: Given 101자, Then 저장되지 않는다 (REJ-42).
- ⚠ AC-17-5: Given 회원 B, When 회원 A의 메모를 어떤 주소로든 요청하면, Then 받을 수 없다 (REJ-44).
- ⚠ AC-17-6: Given 발송됐지만 언박싱 전인 회차, Then 메모 칸이 없다 (REJ-43).

**US-18 구독 마무리**
- AC-18-1: Given 진행 중 구독, When [구독 마무리하기]에 들어오면, Then 맨 위에 US-18 문구와 글자 하나 다르지 않은 마지막 인사 편지, 아래에 작별 안부 칸과 [구독을 마무리합니다]가 있다.
- AC-18-2: Given 그 화면, When [구독을 마무리합니다]를 누르면, Then 추가 확인·혜택 경고·쉬어가기 없이 바로 구독이 마무리된다 (INV-13).
- AC-18-3: Given 읽는 중 회차가 있는 회원이 마무리, Then 그 회차는 그대로 발송·언박싱까지 진행된다 (INV-14).
- AC-18-4: Given 회원이 남긴 작별 안부, Then 책방지기 관리자 화면에서 읽을 수 있다.
- ⚠ AC-18-5: Given 1,001자 안부, Then 버튼이 비활성이다 (REJ-46).
- ⚠ AC-18-6: Given 결제 대기 회차가 있는 회원이 마무리, Then 그 회차는 취소된다 (REJ-47).
- ⚠ AC-18-7: Given 구독이 없거나 이미 마무리된 회원, Then 마이페이지에 [구독 마무리하기]가 없다 (REJ-45).
- ⚠ AC-18-8: Given 회원 A가 남긴 작별 안부, When 회원 B가 어떤 주소·데이터 요청으로든 요청하면, Then 받을 수 없다 (INV-19, NFR-09).

**US-19 주소록**
- AC-19-1: Given 주문 접수 주문 1건, 읽는 중 회차 1건, 발송된 회차 1건, When [주소록 내려받기], Then 엑셀에서 바로 열리는 파일에 2건만, 한글이 깨지지 않고, 결제 시점 배송지로 담긴다 (INV-17).
- ⚠ AC-19-2: Given 발송 대기 0건, Then 파일 대신 "지금 보낼 책이 없어요" (REJ-48).
- ⚠ AC-19-3: Given 일반 회원, Then 주소록을 받을 수 없다 (REJ-49).
- ⚠ AC-19-4: Given 취소 요청 주문 1건과 취소 요청 표시가 있는 읽는 중 회차 1건만 있음, When [주소록 내려받기], Then 두 건 모두 빠져 "지금 보낼 책이 없어요"가 보인다 (INV-17).

**US-20 회차 취소·환불**
- AC-20-1: Given 읽는 중 회차, When 회원이 [취소 요청], 책방지기가 [환불]하면, Then 결제가 환불되고 회차는 취소, 회원은 새 편지를 쓸 수 있다.
- AC-20-5: Given 취소 요청 표시가 있는 회차, When 회원이 [취소 요청 철회]를 누르면, Then 표시가 지워지고 창가 상태는 그대로이며 책방지기는 [발송]할 수 있다.
- AC-20-6: Given 취소 요청 표시가 있는 회차, When 책방지기가 [취소 거절]을 누르면, Then 표시가 지워지고 환불은 없으며, 회원 창가에 "책방지기가 취소 요청을 받지 않았어요. 책은 그대로 보내드려요"가 보인다.
- ⚠ AC-20-2: Given 발송된 회차, Then [취소 요청]이 없다 (REJ-50).
- ⚠ AC-20-3: Given 취소 요청 중 회차, Then [발송]이 막힌다 (REJ-51).
- ⚠ AC-20-4: Given 회차 환불 실패 또는 [환불] 2회 클릭, Then AC-10-3·AC-10-5와 같이 상태 유지·1회만 처리된다 (REJ-52).
- ⚠ AC-20-7: Given 이미 환불된 회차, When 회원이 철회를 시도하면, Then 회차는 취소 상태 그대로이고 현재 상태가 안내된다 (REJ-58).
