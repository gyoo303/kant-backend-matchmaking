# 06. 수용 기준 (P6)

- 입력: `05-user-stories.md` (US-01~20, REJ-01~32)
- 응답 형식: 오류는 모두 `{"detail": "<사유>"}` (NFR-02). 성공은 200 (D-013).
- 상태 코드: 도메인 규칙 위반 400, 인증 실패 401, 없는 대상·보관 정보 권한 없음 404, 입력 형식 오류 422 (REQ-060~062, REQ-T12). 방장 아님·참가자 아님의 코드는 ARCH-Q-01이 다르게 정하면 그 코드로 이 문서를 갱신한다(기본 400).
- "참가자"는 현재 참가 중인 회원, "방장"은 현재 방장이다. 시간 값은 서버 시각.

## 1. 기능 AC

### US-01 방 생성
- AC-01-1: Given 어떤 방에도 참가하지 않은 회원, When 제목 "  즐겜 방  "으로 생성, Then 200, 방 제목 "즐겜 방", 정원 4, 방장 = 그 회원, 참가자 1명(A팀), 이용 기록 1건(퇴장 시각 없음)
- AC-01-2: Given 같은 회원, When 제목 "   " 또는 21자 제목으로 생성, Then 400, 방·참가·기록 0건 추가
- AC-01-3: Given 이미 방 X에 참가 중인 회원, When 새 방 생성, Then 400, 새 방 없음
- AC-01-4: Given 회원, When 제목과 함께 정원 10을 보냄, Then 200, 정원 4
- AC-01-5: Given 같은 제목의 활성 방이 있음, When 같은 제목으로 생성, Then 200, 서로 다른 방 식별자

### US-02 방 참가
- AC-02-1: Given 참가자 1명(A팀)인 활성 방, When 다른 회원이 참가, Then 200, 참가자 2명, 새 참가자 A팀, 입장 순서 2
- AC-02-2: Given A팀 2명·B팀 1명, When 참가, Then 200, B팀 배정 (A팀에 자리가 없음)
- AC-02-3: Given 참가자 4명, When 참가, Then 400, 참가자 4명 유지
- AC-02-4: Given 다른 방에 참가 중인 회원, When 참가, Then 400
- AC-02-5: Given 삭제된 방, When 참가, Then 400
- AC-02-6: Given 없는 방 식별자, When 참가, Then 404
- AC-02-7: Given 이미 이 방에 참가 중, When 같은 방에 참가 요청, Then 200, 이용 기록 수 변화 없음
- AC-02-8: Given 이 방에서 나갔던 회원, When 다시 참가, Then 200, 새 이용 기록 1건, 이전 기록보다 큰 입장 순서, 이전 기록은 이용 로그로 남음(D-025)
- AC-02-9: Given A팀 1명·B팀 2명(팀 이동으로 A팀에 빈자리), When 참가, Then 200, A팀 배정 (D-024)

### US-03 제목 변경
- AC-03-1: Given 방장, When 제목 "새 제목"으로 변경, Then 200, 제목 변경
- AC-03-2: Given 방장 아닌 참가자, When 변경, Then 400(ARCH-Q-01), 제목 그대로
- AC-03-3: Given 삭제된 방, When 변경, Then 400
- AC-03-4: Given 방장, When 공백뿐인 제목, Then 400

### US-04 본인 팀 변경
- AC-04-1: Given A팀 참가자, B팀 1명, When B팀으로 변경, Then 200, 본인 B팀
- AC-04-2: Given B팀 2명, When A팀 참가자가 B팀으로 변경, Then 400, 팀 그대로
- AC-04-3: Given 이 방 참가자가 아닌 회원, When 변경, Then 400(ARCH-Q-01)
- AC-04-4: Given 참가자, When 팀 값 "C", Then 422
- AC-04-5: Given 삭제된 방, When 변경, Then 400
- AC-04-6: Given A팀 참가자, When A팀으로 변경, Then 200, 변경 없음

### US-05 나가기·위임·빈 방 삭제
- AC-05-1: Given 참가자 3명(방장 입장 순서 1), When 입장 순서 2인 참가자가 나감, Then 200, 그 기록에 퇴장 시각, 방장 그대로
- AC-05-2: Given 참가자 3명, When 방장이 나감, Then 200, 남은 사람 중 입장 순서가 가장 빠른 참가자가 방장
- AC-05-3: Given 참가자 1명, When 나감, Then 200, 방 삭제(사유 참가자 없음, 삭제 시각 있음), 공개 목록에서 사라짐, 이용 기록 보존
- AC-05-4: Given 이 방 참가자가 아닌 회원, When 나가기, Then 400(ARCH-Q-01)
- AC-05-5: Given 방에서 나간 회원, When 다른 방 참가, Then 200

### US-06 게임 시작(해산)
- AC-06-1: Given A팀 2명·B팀 2명, When 방장이 시작, Then 200, 방 삭제(사유 게임 시작), 4명 모두 퇴장 시각 기록, 승패·결과 데이터 0건
- AC-06-2: Given 해산 직후, When 4명 중 한 명이 새 방 생성, Then 200
- AC-06-3: Given A·B 각 2명, When 방장 아닌 참가자가 시작, Then 400(ARCH-Q-01), 방 활성 유지
- AC-06-4: Given 참가자 3명 또는 A팀 3명·B팀 1명, When 방장이 시작, Then 400, 방 활성 유지
- AC-06-5: Given 이미 해산된 방, When 시작 재요청, Then 400, 삭제 시각·사유 변화 없음
- AC-06-6: Given 없는 방, When 시작, Then 404

### US-07 방 상세·현재 참가 방
- AC-07-1: Given 활성 방, When 상세 조회, Then 200, 제목·현재 인원·정원 4·방장·참가자별 닉네임과 팀 포함, 입장 순서·비밀번호 해시 미포함
- AC-07-2: Given 방에 참가 중인 회원, When 현재 참가 방 조회, Then 200, 그 방 식별자. 참가 중이 아니면 200, 방 없음
- AC-07-3: Given 참가 중인 회원이 로그아웃 후 재로그인, When 현재 참가 방 조회, Then 같은 방
- AC-07-4: Given 게임 시작으로 해산된 방, When 상세 조회, Then 해산을 나타내는 응답(형식은 ARCH-Q-04), 참가자 정보 미포함
- AC-07-5: Given 없는 방, When 상세 조회, Then 404이며 AC-07-4의 해산 응답과 구분됨

### US-08 회원가입
- AC-08-1: Given 미사용 아이디 "player01"·닉네임 "용감한고양이"·비밀번호 8자, When 가입, Then 200, 응답에 비밀번호·해시 없음, 저장된 비밀번호는 해시
- AC-08-2: When 아이디 "Ab", "PLAYER01", 21자 아이디, Then 400
- AC-08-3: When 닉네임 1자·13자·특수문자 포함, Then 400
- AC-08-4: When 비밀번호 7자, Then 400
- AC-08-5: Given 이미 쓰는 아이디 또는 닉네임, When 가입, Then 400

### US-09 로그인
- AC-09-1: Given 가입한 회원, When OAuth2 양식으로 올바른 아이디·비밀번호, Then 200, `access_token`과 `token_type: bearer`
- AC-09-2: When 틀린 비밀번호 또는 없는 아이디, Then 401, 두 경우 같은 `detail`

### US-10 로그아웃
- AC-10-1: Given 유효 토큰, When 로그아웃, Then 200, 그 토큰 블랙리스트 등록
- AC-10-2: Given 로그아웃한 토큰, When 아무 로그인 필요 API 요청, Then 401
- AC-10-3: Given 방 참가 중인 회원, When 로그아웃, Then 참가 상태·방장 변화 없음

### US-11 비로그인 차단
- AC-11-1: When 토큰 없이 방 목록·생성·참가 API 요청, Then 401
- AC-11-2: When 만료되거나 위조된 토큰, Then 401
- AC-11-3: When 로그인하지 않은 브라우저로 방 목록 화면 접근, Then 로그인 화면으로 이동
- AC-11-4: When 토큰 없이 회원가입·로그인 요청, Then 막히지 않음

### US-12 공개 방 목록
- AC-12-1: Given 활성 방 12개(정원 찬 방 2개 포함)·삭제 방 3개, When 기본 조회, Then 200, 10건, 전체 건수 12, 생성 시각 최신순, 삭제 방 없음
- AC-12-2: When 빈자리 필터, Then 전체 건수 10
- AC-12-3: Given 제목 "Fun Room", When 검색어 "  fun ", Then 포함
- AC-12-4: Given 제목 "100%"와 "100점", When 검색어 "%", Then "100%"만
- AC-12-5: When 정렬 오래된순, Then 생성 시각 오름차순, 같으면 방 식별자 오름차순
- AC-12-6: When 페이지 크기 50, Then 최대 50건. 크기 51·0, 페이지 0, 잘못된 정렬 값 → 422
- AC-12-7: When 마지막 페이지를 넘는 페이지, Then 200, 빈 목록, 전체 건수 유지
- AC-12-8: 정원이 찬 방은 마감 여부가 참으로 표시됨

### US-13 이용 이력
- AC-13-1: Given 회원 A의 기록 3건(하나는 참가 중), When A가 조회, Then 200, 3건, 입장 시각 최신순, 참가 중 기록은 퇴장 시각 없음·'참가 중' 표시 가능
- AC-13-2: Given 회원 B의 기록, When A가 조회, Then B 기록 0건
- AC-13-3: Given 같은 방 재입장 2회, Then 별도 기록 2건
- AC-13-5: Then 응답 항목에 기록 ID가 없고, 방 ID·방 제목·입장 시각·퇴장 시각·참가 중 여부·방 삭제 여부만 있음(D-025)
- AC-13-4: When 페이지 크기 51, Then 422

### US-14 보관 정보
- AC-14-1: Given A가 참가했던 삭제 방, When A가 보관 정보 조회, Then 200, 제목·정원·생성 시각·삭제 시각과 A의 기록만, 다른 회원 정보 없음
- AC-14-2: Given 참가한 적 없는 삭제 방, When 조회, Then 404
- AC-14-3: Given 보관 정보 화면, Then 참가·복구 버튼 없음

### US-15 공개 방 목록 화면(메인)
- AC-15-1: Given 로그인, When 첫 화면, Then 공개 방 목록·생성 폼(제목 입력 1개, "2vs2·4명 고정" 안내)
- AC-15-2: Given 참가 중, Then 상단에 현재 방 링크. 방이 해산된 뒤 다음 조회에서 링크 사라짐
- AC-15-3: Given 정원 찬 방, Then '정원 마감' 표시, 참가 버튼 비활성
- AC-15-4: When 검색어를 바꿈, Then 1페이지로. When 페이지 이동, Then 검색·필터·정렬 유지
- AC-15-5: Given 화면 열림, Then 목록 조회 요청 간격 1초(±0.5초), 동시에 진행 중인 조회 최대 1건
- AC-15-6: When 탭을 숨김, Then 조회 0건. When 돌아옴, Then 1초 안에 조회
- AC-15-7: When 생성이 거부됨, Then 화면이 멈추지 않고 사유 문구 표시

### US-16 방 상세 화면(현황 대시보드)
- AC-16-1: Given 참가자, Then 인원/정원, A팀·B팀 닉네임, 방장 표시. 다른 사람이 참가하면 2초 안에 반영
- AC-16-2: Given 방장, Then 제목 변경·게임 시작 버튼 보임. 방장이 아니면 둘 다 안 보임
- AC-16-3: When 방장이 게임 시작 성공, Then 방 상세 조회 중단, 공개 방 목록으로 이동
- AC-16-4: Given 다른 참가자 화면, When 방장이 시작, Then 다음 조회에서 해산을 확인하고 공개 방 목록으로 이동(해산 안내 문구)
- AC-16-5: When 조회가 통신 실패, Then 마지막 정보 유지, "최신 정보를 불러오지 못했습니다" 표시, 다음 주기 재시도
- AC-16-6: When 조회가 401, Then 폴링 중단, 로그인 화면 안내
- AC-16-7: When 없는 방 상세, Then 해산 안내와 다른 "방을 찾을 수 없습니다" 안내

### US-17 회원가입·로그인·내 기록 화면(목록)
- AC-17-1: When 가입 실패, Then 같은 화면에 사유 표시, 입력한 아이디·닉네임 유지(비밀번호 제외)
- AC-17-2: Given 기록 0건, Then "아직 이용 기록이 없습니다" 표시
- AC-17-3: Given 기록 11건, Then 10건과 다음 페이지 이동
- AC-17-4: When 삭제 방 기록을 선택, Then 보관 정보(US-14) 표시

### US-18 도전 A (Should, 사용자 요청 시)
- AC-18-1: Given 빈자리 1개인 방, When 서로 다른 회원 10명이 동시에 참가, Then 성공 1건, 거부 9건, 참가자 4명
- AC-18-2: Given 같은 회원, When 서로 다른 방 2개에 동시 참가 + 방 생성 1건, Then 현재 참가 1건
- AC-18-3: Given B팀 1명, When 서로 다른 A팀 참가자 2명이 동시에 B팀 변경, Then 성공 1건, B팀 2명
- AC-18-4: Given A·B 각 2명, When 방장이 시작 5건 동시, Then 성공 1건, 해산 1회
- AC-18-5: Given A·B 각 2명, When 시작과 한 참가자의 나가기가 동시, Then (해산 성공·나가기 거부) 또는 (나가기 성공·시작 거부) 둘 중 하나이며 해산된 방에 참가자 0명

### US-19 도전 B (Could)
- AC-19-1: When 게임 시작 성공, Then 응답 뒤 콘솔에 방 식별자·해산 시각이 담긴 해산 로그 1줄
- AC-19-2: Given 기록 1,000건, When 이력 CSV 다운로드, Then 본인 기록 1,000행 + 헤더, 다른 회원 기록 0행

### US-20 도전 C (Could)
- AC-20-1: Given 목록 캐시, When 참가 성공 직후 목록 조회, Then 바뀐 인원 반영
- AC-20-2: When 게임 시작 직후 목록 조회, Then 해산된 방 없음
- AC-20-3: Given `.env` 없이 환경변수만 설정, Then 서버 기동
