# 06. 수용 기준 (P6)

- 입력: `05-user-stories.md`(US-01~30, REJ-01~17), `03-domain.md`(INV), `decision-log.md`
- 성공 응답은 발제 시연 표기에 맞춰 200으로 통일한다(D-010). 에러 응답 본문은 `{"detail": <문자열>}`이다(422 본문 형식은 Architect ADR로 확정).
- QA는 AC-ID를 테스트 케이스 ID와 1:1로 연결한다. 시드 데이터(US-13)를 기본 Given으로 쓴다.
