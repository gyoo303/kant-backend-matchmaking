# 07. 화면 구성 (PM-SCR)

- 입력: PM-US, PM-AC, PM-DOMAIN. UX-CTX-ORCH 미배포 → 색·폰트·일러스트 스타일은 UI/UX 에이전트가 정한다. 여기서는 **구성 요소와 우선순위**만 정한다.
- 경로는 후보다. 최종 경로·폴더는 Architect가 정한다(REQ-T05). 단, KANT 증빙 경로 `/products`, `/products/[id]`는 고정(KANT-R5, R6).

## 2. 공통 요소 (KANT-C7, C8 → 컴포넌트 분리 대상)
| 요소 | 위치 | 구성 | 상태별 표시 |
|---|---|---|---|
| Header | 모든 회원·방문자 화면 | 로고(→ `/`), 테마 서가(→ `/products`), 편지 띄우기(→ `/letters/new`), 장바구니(개수), 로그인 또는 마이페이지 | 비회원: [로그인] / 회원: [마이페이지], 장바구니 개수 / 관리자: [서재] 추가 |
| Footer | 모든 회원·방문자 화면 | 책방 이름(우분투북스·대전 어은동), 사이트 내 링크(테마 서가·편지 띄우기). 사업자 정보·환불 규정·개인정보 처리방침은 기재하지 않음 (D-021) | — |
| ProductCard | 메인 새로 들어온 책, 목록, 관리자 매칭 검색 | 표지(3:4), 제목, 저자, 가격, 테마 표시, 품절 표시 | 품절: "품절" 배지 / 이미지 깨짐: 대체 표지 |
| ThemeSelector | 메인, 목록 | 자연·식문화·생태·로컬(+ 목록은 "전체") | 선택된 테마 강조 |
| WindowScene | 창가, 마이페이지 | 창가 일러스트 3상태 + 상태 문구 | 어두움("편지가 서점에 도착했어요") / 촛불 / 우체통 불빛. 그림의 대체 텍스트는 상태 문구와 같음(NFR-11) |
| BlindBook | 창가, 언박싱 | 실루엣 + 힌트 문장 | 언박싱 전에만 |
| 관리자 레이아웃 | 관리자 화면 | 상단 메뉴(책 관리·주문 처리·서재 작업), 한 열 본문 | — |

## 3. KANT 핵심 3페이지 와이어프레임 (KANT-R1, C2)

### SCR-01 메인 (`/`)
```
┌ Header ─────────────────────────────────────┐
│ [책방 소개 — 대전 어은동 골목 책방, 느린 관계]  │ ← REQ-002, REQ-004
│ [편지 띄우기 안내 한 줄 + 링크]                 │ ← REQ-031
│ 테마 서가                                      │
│ [자연] [식문화] [생태] [로컬]  (카드 4개)        │ ← REQ-010
│ 새로 들어온 책                                 │ ← D-035
│ [ProductCard][ProductCard][ProductCard]...   │
└ Footer (책방 이름·사이트 링크) ─────────────────┘
```
필수 시각 요소: Header, 책방 소개 문구, 테마 카드 4개, ProductCard 1개 이상(새로 들어온 책), Footer.
우선순위: 소개 → 테마 → 새로 들어온 책. 실패 시 새로 들어온 책 영역만 안내 문구(AC-01-4).

### SCR-02 상품 목록 (`/products`)
```
┌ Header ─────────────────────────────────────┐
│ 테마 서가                                      │
│ [전체] [자연] [식문화] [생태] [로컬]            │ ← ThemeSelector, 주소에 반영
│ (선택 테마 한 줄 소개)                          │
│ ┌Card┐ ┌Card┐            360px 2열            │
│ ┌Card┐ ┌Card┐  … 768px 3열 / 1280px 4열       │ ← .map() 렌더링, 균일 간격
│ 빈 테마: "이 서가는 아직 비어 있어요" + 다른 테마│
└ Footer ─────────────────────────────────────┘
```
필수 시각 요소: 테마 선택지 5개, ProductCard 격자(표지 3:4·제목·저자·가격·테마·품절), 빈 상태 문구.

### SCR-03 상품 상세 (`/products/[id]`)
```
┌ Header ─────────────────────────────────────┐
│ ┌ 책방지기 노트 — 최상단, 큰 글씨 ──────────┐ │ ← REQ-012, INV-02
│ └──────────────────────────────────────┘ │
│ [표지 3:4 object-cover]  제목 / 저자          │
│                          테마 · 가격          │
│                          [장바구니 담기]       │ ← 품절이면 비활성
│ ▸ 출판사 소개 (접힘, 없으면 숨김)              │
│ ← 테마 서가로 돌아가기                         │
└ Footer ─────────────────────────────────────┘
```
모바일: 노트 → 표지 → 정보·버튼 → 출판사 소개 순 한 열. PC: 노트 아래 표지·정보 2단.
필수 시각 요소: 책방지기 노트(최상단), 표지, 제목, 저자, 가격, 테마, [장바구니 담기], 목록 링크.

### SCR-04 상품 없음
```
│ 상품을 찾을 수 없습니다                         │ ← KANT-C14
│ [테마 서가로 가기]                              │
```

## 4. 그 밖의 화면 구성 요소

| SCR-09 장바구니 | 책 줄(표지·제목·수량·금액·빼기), 합계, [주문하기] | 비어 있음 / 품절 줄 / 재고 초과 안내 |
| SCR-10 주문서 | 주문 책 요약, 배송지(기본값), 합계, [결제하기] | 배송지 빈칸 |
| SCR-11 결과 | 주문 번호 + 안내 / 결제 미완료 + [다시 결제하기] | 성공 / 실패 / 재고 부족 |
| SCR-12 주문 현황 | 주문 목록, 주문별 2단계 표시, [취소 요청], [취소 요청 철회] | 접수 / 발송됨 / 취소 요청 / 거절 안내 / 환불 완료 |
| SCR-13 주문 처리 | [주소록 내려받기], 발송 대기·취소 요청 주문 목록, [발송 완료], [환불], [취소 거절] | 환불 실패 안내 / 발송 대기 0건 |
| SCR-14 편지지 | 편지지(안내 문구: 마음 날씨·책의 결), 글자 수, 회차 금액·안내, 배송지 확인, [우체통에 편지 넣기] → 봉투 닫힘 → 결제 → (확정 후) 우체통 들어감 → 창가 (D-041) | 진행 중 회차 있음: 편지지 대신 안내 / 결제 실패: 봉투가 다시 열린 편지지(내용 보존) + [다시 결제하기]·[편지 거두기], 우체통 전환 없음 |
| SCR-15 창가 | WindowScene, 상태 문구(3상태 모두), (발송됨) BlindBook + 힌트 + 코드 입력 링크, [취소 요청](발송 전)·"취소 요청 중" 문구·[취소 요청 철회]·거절 안내, 지난 회차 링크 | 어두움 / 촛불 / 우체통 불빛 / 회차 없음 |
| SCR-16 언박싱 | BlindBook, 힌트, 6자리 입력, [열기] → 공개 전환 → 표지·제목·답장 편지·엽서 사진 → 메모 링크 | 틀린 코드 안내 / 언박싱됨 |
| SCR-17 나의 서가 | 언박싱된 책 목록(표지·제목), 책별 한 줄 메모·날짜, [수정]·[삭제] | 메모 없음 / 100자 초과 |
| SCR-18 구독 마무리 | 마지막 인사 편지(최상단, US-18 고정 문구), 진행 중 회차 안내 한 줄(있을 때), 작별 안부 칸, [구독을 마무리합니다] | 마무리 완료 문구. 확인 팝업 없음 |
| SCR-19 서재 작업 | ① 회차 목록(도착순, 취소 요청 표시 + [환불]·[취소 거절])·편지 전문 ② 책 검색·선택, 답장 편지, 엽서 사진 ③ 힌트 문장, [발송] → 코드 크게 표시 / 작별 안부 목록(하단) | 빠진 항목 표시 / 품절 책 선택 불가 / 발송 완료 코드 |
| SCR-20 관리자 홈 | 오늘 할 일 수(도착한 편지, 발송 대기 주문, 취소 요청), 메뉴 3개 | — |

## 5. 시연 흐름 초안 (KANT-C18, 3~5분)
| 순서 | 화면 | 보여 줄 것 | 시간 |
|---|---|---|---|
| 1 | SCR-01 | 콘셉트 한 줄, Header·Footer, 테마 카드 | 0:30 |
| 2 | SCR-02 | 테마 바꾸기(새로고침 없음), 균일한 격자, 품절 표시, 화면 폭 줄여 반응형 | 0:40 |
| 3 | SCR-03 | 책방지기 노트 최상단, 표지 비율 | 0:20 |
| 4 | SCR-04 | 주소창에 없는 ID → "상품을 찾을 수 없습니다" | 0:15 |
| 5 | SCR-05 | 카카오 로그인 | 0:15 |
| 6 | SCR-09→11 | 장바구니 → 테스트 결제 → 주문 접수 | 0:40 |
| 7 | SCR-14→15 | 편지 쓰기 → 봉투 닫힘 → 테스트 결제 → 우체통 전환 → 어두운 창가·"편지가 서점에 도착했어요" | 0:30 |
| 8 | SCR-19 + SCR-15 | (관리자 창) 편지 열기 → (회원 창) 촛불, 매칭·답장·힌트 → 발송 → 우체통 불빛·코드 | 0:50 |
| 9 | SCR-16→17 | 코드 입력 → 언박싱 → 한 줄 메모 | 0:30 |
| 10 | SCR-18 | 작별 안부 → 바로 마무리 (팝업 없음) | 0:20 |
합계 약 4분 50초. 시간이 부족하면 6, 10을 말로 대신한다(기능은 구현 범위 그대로).
