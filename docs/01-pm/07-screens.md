## 3. KANT 필수 3페이지 와이어프레임 (KANT-R1, C2)

### SCR-01 메인 (`/`)
```
┌ Header ─────────────────────────────────────┐
│ [책방 소개]  어은동 골목 책방 한 단락 + 사진 1장 │  ← REQ-001, 012
│                                              │
│ [테마 서가 4칸]  자연 | 식문화 | 생태 | 로컬     │  ← REQ-010, 011
│   각 칸: 테마 이름 + 한 줄 소개                  │
│          + ProductCard 2~3장 (가로 정렬)        │
│          + "이 서가 둘러보기 →" (<Link>)        │
│   책 0권 테마: "준비 중인 서가입니다"            │  ← AC-01-3
│                                              │
│ [편지 구독 소개] 한 단락 + "편지 쓰러 가기 →"    │  ← REQ-031
└ Footer ─────────────────────────────────────┘
```
필수 시각 요소: Header, 책방 소개 글, 테마 4개 입구(이름·소개·카드), 편지 구독 입구, Footer
반응형: 360px 테마 칸 세로 1열 / 768px 2×2 / 1280px 4열 또는 2×2

### SCR-02 상품 목록 (`/products`)
```
┌ Header ─────────────────────────────────────┐
│ [테마 선택]  전체 | 자연 | 식문화 | 생태 | 로컬   │  ← REQ-011
│ [선택한 테마 이름 + 짧은 소개]                   │
│                                              │
│ [ProductCard 그리드]  .map()으로 렌더            │  ← KANT-R5, C9, C11
│  ┌────┐ ┌────┐ ┌────┐                         │
│  │표지│ │표지│ │표지│  고정 비율, object-cover  │  ← KANT-C10
│  │제목│ │제목│ │제목│                          │
│  │저자│ │저자│ │저자│                          │
│  │가격│ │품절│ │가격│                          │
│  └────┘ └────┘ └────┘                         │
│ 없는 테마 → 전체 목록 + "없는 테마입니다"          │  ← AC-02-5
│ 불러오기 실패 → "책을 불러오지 못했습니다"         │
└ Footer ─────────────────────────────────────┘
```
필수 시각 요소: Header, 테마 선택, 테마 소개, ProductCard 그리드(표지·제목·저자·가격·품절), Footer
반응형: 360px 1열 / 768px 2열 / 1280px 3~4열 (NFR-03)

### SCR-03 상품 상세 (`/products/[id]`)
```
┌ Header ─────────────────────────────────────┐
│ ┌ 책방지기 노트 ───────────────────────────┐ │  ← REQ-013 최상단, 큰 글씨
│ │ "이 책을 읽고 … "                        │ │
│ └──────────────────────────────────────────┘ │
│ [표지 이미지 고정 비율 object-cover]            │
│ 제목 / 저자 / 테마 / 가격                       │
│ [장바구니 담기]  또는  [품절](비활성)            │  ← AC-03-4
│ 출판사 소개                                     │
│ ← 목록으로 (<Link>)                             │
└ Footer ─────────────────────────────────────┘
노트 없음 → 출판사 소개가 맨 위
없는 ID → "상품을 찾을 수 없습니다" + [목록으로] (<Link>)  ← KANT-C14
```
필수 시각 요소: Header, 책방지기 노트(최상단), 표지, 제목·저자·테마·가격, 장바구니 버튼/품절, 출판사 소개, 목록 링크, Footer
반응형: 360·768px 세로 1열 / 1280px 노트는 전체 폭, 그 아래 표지(좌)·정보(우) 2열 허용

## 4. 그 밖의 화면 (구성 요소 · 상태별 표시)

| SCR | 구성 요소 (위→아래) | 상태별 표시 |
|---|---|---|
| SCR-04 로그인 | 짧은 환영 문구, [카카오로 시작하기], [네이버로 시작하기] | 기본 / 실패 안내 / 키 미설정 안내(AC-20-3) |
| SCR-05 책 관리 | 목록(제목·테마·가격·재고, [수정]), [새 책]; 폼: 제목·저자·출판사·가격·표지 이미지·출판사 소개·테마(4개 중 1)·책방지기 노트·재고, [저장] | 목록 비어 있음 / 입력 오류 항목 표시 / 저장 완료 |
| SCR-06 장바구니 | 책 행(표지·제목·가격·수량 조절·빼기), 합계, [주문하기] | 비어 있음 / 품절 포함(주문 비활성) / 재고 초과 안내 |
| SCR-07 주문·결제 | ① 배송지(받는 사람·주소·연락처, 기본값 채움) ② 주문 요약 ③ 결제 수단(카드·간편결제) [결제하기] ④ 완료 화면 | 입력 오류 / 결제 실패(다시 결제) / 재고 부족 / 완료 |
| SCR-08 마이페이지 | ① 창가 등불 그림(현재 회차) 또는 [새 편지 쓰기] ② 주문 내역(상태 문구) ③ 나의 서가 입구 ④ [구독 마무리하기](구독 중일 때만) | 등불: 결제 대기 / 어두움 / 촛불 / 우체통 불빛 / 회차 없음 (AC-12-1~4) |
| SCR-09 일반 주문 | 결제 완료 주문 목록(주문일·손님·책·배송지·[발송 처리]), [주소록 내려받기] | 비어 있음 / 발송 처리 완료 |
| SCR-10 편지 쓰기 | 편지지(자유 글, 글자 수), [우체통에 편지 넣기] → 배송지 확인 → 결제 → 봉투·우체통 연출 → 완료 문구 | 진행 회차 있음(편지지 대신 안내) / 글자 수 오류 / 결제 실패(편지 보존) / 완료 |
| SCR-11 회차 보기 | 발송됨: 실루엣·힌트·코드 입력(6칸)·[열어보기] / 언박싱됨: 표지·제목·답장 편지·엽서 사진·서가 메모 칸 | 발송 전(등불만) / 발송됨 / 틀린 코드 / 언박싱됨 |
| SCR-12 나의 서가 | 언박싱한 책 카드(표지·제목)와 메모·날짜 목록 | 비어 있음("첫 편지를 보내 보세요") |
| SCR-13 구독 마무리 | ① 책방지기 마지막 인사 편지 ② 작별 안부 칸(선택) ③ [구독을 마무리합니다] → 감사 문구 | 구독 중 아님(안내) / 완료. 팝업·경고·일시정지 없음 |
| SCR-14 서재 작업 목록 | "편지 도착"·"읽는 중" 회차(오래된 순, 손님 이름·도착일·상태), [주소록 내려받기] | 비어 있음 |
| SCR-15 서재 작업 화면 | **한 열 세로**: ① 손님 편지 전문 ② 책 검색(재고 있는 책만)·선택, 답장 편지, 엽서 사진 1장 ③ 힌트 문장, [발송] → 6자리 코드 크게 표시 | 첫 열람 시 "읽는 중" 전환 / 빈 항목 안내 / 업로드 오류 / 발송 완료(코드 표시) |
| SCR-16 구독자 보기 | 손님별 구독 상태·회차 수·작별 안부 | 구독 중 / 해지됨 |

## 5. 시연 흐름 초안 (KANT-C18, US-20, 약 5분)
