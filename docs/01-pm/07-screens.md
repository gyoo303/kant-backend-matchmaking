# 07. 화면 구성 & 와이어프레임 (P7)

- 입력: US-11~17, D-012, REQ-072~097
- 화면은 Jinja2 템플릿 페이지와 Swagger UI(`/docs`)뿐이다(REQ-128). 시각 디자인(색·폰트)은 정하지 않는다.
- 경로는 **후보**다. 확정은 ARCH.
- 발제 핵심 3화면 대응(D-012): 메인 = SCR-03 공개 방 목록, 목록 = SCR-05 내 기록, 현황 대시보드 = SCR-04 방 상세

## 1. 화면 목록

| ID | 화면 | 경로 후보 | 액터 | 관련 US | 갱신 | 마일스톤 |
|---|---|---|---|---|---|---|
| SCR-01 | 회원가입 | `/signup` | 방문자 | US-08, US-17 | 제출 시 | M5 |
| SCR-02 | 로그인 | `/login` | 방문자 | US-09, US-11, US-17 | 제출 시 | M5 |
| SCR-03 | 공개 방 목록 (메인) | `/` 또는 `/rooms` | 회원 | US-01, US-02, US-12, US-15 | 1초 폴링 | M5 |
| SCR-04 | 방 상세 (현황 대시보드) | `/rooms/{id}` | 회원·방장 | US-02~07, US-16 | 1초 폴링 | M5 |
| SCR-05 | 내 기록 (목록) | `/me/history` | 회원 | US-13, US-17 | 수동 | M5 |
| SCR-06 | 삭제 방 보관 정보 | `/me/history/{room_id}` | 과거 참가자 | US-14 | 수동 | M5 |
| SCR-07 | Swagger UI | `/docs` | 시연자 | 전체 API | — | M3~ |

- 비로그인으로 SCR-03~06에 들어오면 SCR-02로 이동한다(D-005).

## 2. 공통 요소

- **기본 레이아웃**: 머리글(서비스 이름, 로그인 시 닉네임·[내 기록]·[로그아웃], 비로그인 시 [로그인]·[회원가입]), 본문, 바닥글(서비스 이름).
- **안내 영역**: 성공·거부 사유·통신 실패·인증 만료 문구를 본문 위에 한 줄로 보인다. 거부 시 화면은 멈추지 않는다(REQ-019).
- **방 행**: 제목 | 현재 인원/정원 | 생성 시각 | 상태(빈자리 / 정원 마감) | [참가]. SCR-03 목록에서 반복 사용.
- **기록 행**: 방 제목 | 입장 시각 | 퇴장 시각 또는 '참가 중' | (삭제된 방이면 [보관 정보]). SCR-05에서 반복 사용.
- **페이지 이동**: [이전] 현재 페이지 / 전체 페이지 [다음]. SCR-03·05 공용.
- **폴링 규칙**(SCR-03·04): 1초 간격, 겹치지 않음, 늦은 응답 버림, 탭 숨김 시 중단·복귀 시 즉시 조회, 통신 실패 시 마지막 정보 유지 + "최신 정보를 불러오지 못했습니다", 401이면 중단 후 로그인 안내(REQ-088~097).

## 3. 핵심 3화면 와이어프레임

### SCR-03 공개 방 목록 (메인)

```
┌ 기본 레이아웃 ─────────────────────────────────────────┐
│ [참가 중인 방: "즐겜 방" 바로가기]   ← 참가 중일 때만 (REQ-076)
│ [안내 영역]
│ ┌ 방 만들기 ─────────────────────────────┐
│ │ 제목 [__________] [만들기]               │ ← 제목만 (REQ-074)
│ │ 2vs2 · 4명 고정                          │
│ └─────────────────────────────────────────┘
│ 검색 [______] [ ] 빈자리 있는 방만  정렬 [최신순 ▼]
│ 전체 12개
│ 제목     | 인원 | 생성 시각   | 상태       |
│ 즐겜 방  | 3/4  | 10-28 14:02 | 빈자리     | [참가]
│ 랭크 연습 | 4/4  | 10-28 13:50 | 정원 마감  | [참가](비활성) ← REQ-087
│ ...
│ [이전] 1 / 2 [다음]
└────────────────────────────────────────────────────────┘
데이터 없음 → "조건에 맞는 방이 없습니다. 새 방을 만들어 보세요"
```

- 필수 표시 요소: 현재 참가 방 링크(조건부), 생성 폼(제목 1칸 + 고정 인원 안내), 검색·빈자리 필터·정렬, 전체 건수, 방 행, 페이지 이동, 안내 영역
- 상태별: 참가 중이면 다른 방 [참가]·[만들기]를 눌러도 서버가 거부하고 사유를 보인다(REQ-033). 해산으로 목록에 돌아오면 "게임이 시작되어 방이 해산되었습니다"를 안내한다(REQ-092).

### SCR-04 방 상세 (현황 대시보드)

```
┌ 기본 레이아웃 ─────────────────────────────────────────┐
│ [안내 영역]
│ 즐겜 방  [제목 변경](방장만)          인원 3/4
│ ┌ A팀 (2/2) ─────────┐  ┌ B팀 (1/2) ─────────┐
│ │ ★용감한고양이 (방장) │  │ 빠른토끼             │
│ │ 조용한여우           │  │ (빈자리)             │
│ └─────────────────────┘  └─────────────────────┘
│ [B팀으로 이동](본인)  [나가기]
│ [게임 시작](방장만, A·B 각 2명일 때 활성)
└────────────────────────────────────────────────────────┘
참가자가 아닌 회원 → 팀 구성 + [참가](빈자리 있을 때)
```

- 필수 표시 요소: 제목, 현재 인원/정원, A팀·B팀별 닉네임과 빈자리, 방장 표시, 본인 팀 이동, 나가기, 제목 변경·게임 시작(방장만), 안내 영역. 입장 순서는 보이지 않는다(REQ-045).
- 상태별
  - 게임 시작 성공(방장) → 조회 중단, SCR-03으로 이동
  - 다음 조회에서 해산 확인(다른 참가자) → SCR-03으로 이동 + 해산 안내
  - 없는 방·접근 불가 → "방을 찾을 수 없습니다" (해산 안내와 다름, REQ-094)
  - 통신 실패 → 마지막 구성 유지 + 실패 안내

### SCR-05 내 기록 (목록)

```
┌ 기본 레이아웃 ─────────────────────────────────────────┐
│ 내 이용 기록   전체 11건
│ 방 제목   | 입장 시각   | 퇴장 시각           |
│ 즐겜 방   | 10-28 14:02 | 참가 중             |
│ 랭크 연습 | 10-28 13:00 | 10-28 13:40         | [보관 정보]
│ ...
│ [이전] 1 / 2 [다음]
└────────────────────────────────────────────────────────┘
데이터 없음 → "아직 이용 기록이 없습니다"
```

- 필수 표시 요소: 기록 행(입장 시각 최신순), 전체 건수, 페이지 이동, 삭제 방의 [보관 정보]. 검색·필터·정렬 선택은 없다(REQ-055).

## 4. 그 밖의 화면

| 화면 | 구성 요소 | 상태별 표시 |
|---|---|---|
| SCR-01 회원가입 | 아이디·닉네임·비밀번호 입력, 각 규칙 안내(4~20자 영문 소문자·숫자 / 2~12자 / 8자 이상), [가입] | 실패 시 사유 표시·아이디·닉네임 유지, 성공 시 SCR-02로 |
| SCR-02 로그인 | 아이디·비밀번호, [로그인], [회원가입] 링크 | 실패 시 "아이디 또는 비밀번호가 올바르지 않습니다", 인증 만료로 왔으면 만료 안내 |
| SCR-06 보관 정보 | 제목, 정원, 생성 시각, 삭제 시각, 본인 입장·퇴장 기록 | 참가·복구 버튼 없음, 권한 없으면 "찾을 수 없습니다" |

## 5. 시연 흐름 초안 (EV-10, 5분)

1. (0:00) SCR-02 로그인 → SCR-03 메인: 시드 방 목록, 검색·빈자리 필터·페이지 (실제 DB 데이터)
2. (0:50) SCR-03에서 방 생성 → SCR-04: 다른 브라우저 3개로 참가, 1초 폴링으로 팀 구성이 바뀌는 모습, 본인 팀 이동
3. (1:50) Swagger(`/docs`): Authorize 후 정상 요청 200 (참가·팀 변경)
4. (2:30) 규칙 위반 400: 정원 마감 방 참가, 마감된 팀으로 이동, 방장이 아닌 참가자의 게임 시작, 3:1 구성에서 게임 시작
5. (3:20) SCR-04에서 방장이 게임 시작 → 4개 화면 모두 SCR-03으로 복귀, 목록에서 방 사라짐 → SCR-05에서 기록·보관 정보 확인
6. (4:10) 로그아웃 → 같은 토큰으로 Swagger 요청 401
7. (4:40) 정리 (도전 A 채택 시 동시 참가 스크립트 결과 한 줄)
