## [화면] SCR-03 공개 방 목록(메인) (TKT-FE-M5-03)
결론: 수용 기준 7개 중 6개 충족, 1개 부분 충족(AC-15-2 해산 후 링크 사라짐 미확인) · 실제 API 기준(SQLite 임시 DB, PostgreSQL 미확인)

### 사람이 결정할 것
- **공통 CSS 보완(제안)**: 375px에서 표의 제목 칸이 다른 칸(`nowrap`)에 밀려 한두 글자 폭으로 줄어든다(페이지 가로 넘침은 없고 표 안에서만 좁아짐). `app.css`에 제목 칸 최소 폭 한 줄(예: `.cell-title { min-width: 8em; }`)이 필요하다. `app.css`는 이 티켓 산출 밖 공통 파일이라 고치지 않았다. 별도 커밋으로 넣을지 정해 주세요.

### 이해 가이드
- 데이터 흐름: 서버가 URL 조건을 `#room-list`의 `data-*` 속성으로 넘긴다 → `rooms.js`의 `initRoomListPage()`가 조건을 읽어 1초마다 `GET /api/rooms?…`와 `GET /api/me/room`을 부른다(`startPolling`) → 목록 내용이 바뀌었을 때만 표를 다시 그린다 → 생성·참가는 `apiRequest` 후 성공하면 상세로 이동, 실패하면 안내 영역에 사유.
- 검색·필터·정렬은 일반 HTML 폼(GET `/`)이라 제출하면 페이지가 새로 열리고 1페이지부터 시작한다(사용자 확인 ③). 페이지 이동 링크는 같은 조건을 그대로 붙인다.
- 먼저 읽을 파일: `src/templates/rooms/list.html`, `src/static/js/rooms.js`(SCR-03 부분), (공통) `src/static/js/api.js`

### 구현 중 자율 결정

#### 검색 조건을 JS에 넘기는 방법
- 결정: 서버의 `cond`를 `#room-list`의 `data-keyword`·`data-available-only`·`data-sort`·`data-page` 속성으로 넘긴다 — PAGE-03(`cond` 컨텍스트)
- 선택지: **A. data 속성 (권장·채택)** / B. `{{ cond | tojson }}`을 `<script>` 안에 넣음
- 권장 이유: Jinja 자동 이스케이프가 그대로 적용되고(교안 3장 수준), 스크립트 안에 서버 값을 직접 끼워 넣지 않는다.
- trade-off: A — 값이 문자열이라 JS에서 숫자·불리언으로 바꿔야 한다. B — 타입은 유지되지만 스크립트 안 삽입이라 이스케이프를 신경 써야 한다.

#### 바뀌었을 때만 다시 그리기
- 결정: 목록 응답을 문자열로 비교해 바뀌었을 때만 표를 다시 그린다 — 07-screens §2 폴링 규칙, frontend-impl 기본 품질(키보드 포커스)
- 선택지: **A. 바뀔 때만 다시 그림 (권장·채택)** / B. 매초 다시 그림
- 권장 이유: 매초 다시 그리면 [참가] 버튼의 키보드 포커스가 1초마다 사라진다.
- trade-off: A — 응답 비교 비용이 조금 든다. B — 코드는 짧지만 키보드 사용자가 버튼을 누르기 어렵다.

#### 폴링 실패 안내와 다른 안내의 구분
- 결정: 통신 실패 안내("최신 정보를 불러오지 못했습니다")만 다음 조회 성공 때 지우고, 해산 안내·거부 사유는 지우지 않는다 — 07-screens §2(통신 실패 시 마지막 정보 유지 + 안내)
- 선택지: **A. 실패 안내만 자동으로 지움 (권장·채택)** / B. 성공할 때마다 안내 영역을 비움
- 권장 이유: 해산 안내·거부 사유가 1초 뒤 사라지면 사용자가 읽을 수 없다.
- trade-off: A — 거부 사유는 다음 동작 전까지 남아 있다. B — 안내가 금방 사라진다.

#### 목록 [참가] 버튼 접근성 이름
- 결정: 버튼 글자는 "참가", 스크린리더용 이름은 "<방 제목> 참가"(`aria-label`) — 07-screens §2 방 행
- 선택지: **A. 방 제목을 붙인 이름 (권장·채택)** / B. 모두 "참가"
- 권장 이유: 같은 이름의 버튼이 10개면 화면 낭독기 사용자가 구분할 수 없다.
- trade-off: A — 제목이 길면 읽는 문구가 길다. B — 구분이 안 된다.
