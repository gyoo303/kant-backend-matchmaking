# 디자인 결정 기록 (UX-DEC)
- 버전: v0.1 / 승인: 조성아 (2026-10-21)
- ④는 `범위`가 `전체`이거나 이번 기능인 결정을 읽고, `금지`를 되살리지 않는다. 결정의 배경이 되는 토큰·컴포넌트 규칙은 `docs/uiux/review/frontend/design-system.md`(UX-PLAN-FE)에 있다.
- PM의 범위 결정(`D-xx`)과 ARCH의 기술 결정(`ADR-xxx`)은 여기에 쓰지 않는다(PIPELINE.md §3.6).

### UX-D-01: 종이·숲·밤하늘 팔레트와 고운 글꼴 한 쌍   [APPROVED by 조성아, 2026-10-21]
- 범위: 전체
- 결정: design-system.md §2 색 토큰과 §3 글꼴(Gowun Batang 제목·긴 글, Gowun Dodum 본문)을 쓴다. 등불색 `--lamp`는 창가 패널 안에서만 쓴다.
- 근거: [근거: REQ-002, REQ-004] 서점 공간의 결과 아날로그적인 온기. 손편지가 핵심 흐름이라 긴 글을 편지처럼 읽히는 바탕체로 둔다.
- 금지: 흰 페이지 배경, 세 번째 글꼴, 등불색을 일반 버튼·링크에 쓰기
- 예외: 소셜 로그인 버튼 브랜드 색, 일러스트 내부 색
- 버린 대안: 흰 바탕 + 검정 기본 shadcn 팔레트(서점의 결이 드러나지 않음)

### UX-D-02: 모바일 Header는 두 줄, 메뉴를 숨기지 않는다   [APPROVED by 조성아, 2026-10-21]
- 범위: Header
- 결정: 360px에서 1줄 로고·장바구니·로그인(마이페이지), 2줄 테마 서가·편지 띄우기. 햄버거 메뉴 없음.
- 근거: 메뉴가 4개뿐이고 손님 대부분이 스마트폰을 쓴다 [근거: REQ-016]. 메뉴 이름 하나에 화면 하나(D-042)가 늘 보여야 길을 잃지 않는다.
- 금지: 햄버거·드롭다운으로 주 메뉴 숨기기
- 예외: 없음
- 버린 대안: 햄버거 메뉴(누르기 전에는 "편지 띄우기"가 보이지 않음)

### UX-D-03: 창가는 사진이 아니라 SVG 일러스트, 밤하늘 패널 안에 둔다   [APPROVED by 조성아, 2026-10-21]
- 범위: `WindowScene` (SCR-06, SCR-15), 메인 첫 화면 그림
- 결정: 창가 상태 4개를 한 SVG 컴포넌트의 상태로 그린다. 상태 차이는 창 안의 빛(어두움/촛불)과 창턱의 물건(봉투/없음), 우체통 불빛으로 구분한다. 상태 문구는 그림 옆(768+) 또는 아래(360)에 함께 둔다.
- 근거: [근거: REQ-034~037], D-043, NFR-11. 빛의 변화만으로는 상태 구분이 어려워 창턱의 물건으로 한 번 더 구분한다 [제안].
- 금지: 진행률 막대, 단계 숫자, 상태 문구 없이 그림만 두기
- 예외: 없음
- 버린 대안: 상태별 사진(의뢰인 사진 제공 여부 미정, Q-UX-09)

### UX-D-04: 메인 첫 화면의 그림은 창가 일러스트   [APPROVED by 조성아, 2026-10-21]
- 범위: SCR-01
- 결정: 책방 소개 글 옆(360px은 아래)에 불 켜진 창가와 우체통 일러스트를 둔다.
- 근거: [근거: REQ-004] "서점 창가의 불빛을 바라보며 기다리는". 공간 사진은 의뢰인 제공 여부가 정해지지 않았다(Q-UX-09).
- 금지: 책 할인 배너, 자동으로 넘어가는 슬라이드
- 예외: Q-UX-09 답으로 공간 사진을 받으면 이 결정을 새 번호로 다시 정한다
- 버린 대안: 새로 들어온 책 슬라이드(판매 정보를 앞세움)

### UX-D-05: 편지류는 같은 편지지 모양으로 보여 준다   [APPROVED by 조성아, 2026-10-21]
- 범위: 책방지기 노트(SCR-03), 손편지(SCR-14, 19), 답장(SCR-16), 마지막 인사 편지(SCR-18)
- 결정: design-system.md §5의 `KeeperNote`, `LetterPaper` 규칙(바탕체, 줄 간격 1.8 이상, 한 줄 최대 `max-w-xl`)
- 근거: [근거: REQ-012, exp-002 §3] 운영자 개인의 목소리 (보통), REQ-031·042·046
- 금지: 편지류를 일반 본문 글꼴·작은 글자로 표시
- 예외: 관리자 목록의 편지 미리보기 한 줄
- 버린 대안: 손글씨체 글꼴(긴 글 가독성이 떨어짐)

### UX-D-06: 마지막 인사 편지의 줄바꿈 위치   [APPROVED by 조성아, 2026-10-21]
- 범위: SCR-18
- 결정: 아래처럼 5줄로 나누고 서명 줄은 오른쪽 정렬. 글자는 US-18 그대로이며 줄바꿈만 넣는다(PM이 UX에 맡김).
  ```
  우분투북스와 함께 숨을 고르셨던 시간들이
  좋은 쉼이 되었기를 바랍니다.
  계절이 바뀌어 책 한 줄의 온기가 필요해지면,
  언제든 다시 찾아와 주세요.
                ㅡ어은동에서, 우분투북스 책방지기 드림
  ```
- 근거: US-18 정상 흐름 1, AC-18-1(글자 하나 다르지 않게)
- 금지: 글자·띄어쓰기·문장부호 바꾸기
- 예외: 360px에서 한 줄이 넘치면 브라우저 자동 줄바꿈은 허용(강제 줄바꿈 위치는 유지)
- 버린 대안: 줄바꿈 없는 한 문단

### UX-D-07: 언박싱 코드는 입력칸 하나로 받는다   [APPROVED by 조성아, 2026-10-21]
- 범위: SCR-16
- 결정: `<input inputmode="numeric" autocomplete="one-time-code" maxlength="6">` 한 칸, 글자 사이를 넓혀 6자리처럼 보이게 한다.
- 근거: 상자 속 카드의 숫자를 옮겨 적는 흐름(REQ-041). 칸을 6개로 나누면 붙여넣기·스크린 리더·키보드 이동이 번거로워진다.
- 금지: 칸 6개 분리 입력, 카메라·QR(INV-10)
- 예외: 없음
- 버린 대안: 6칸 분리 입력

### UX-D-08: 네이버 로그인 버튼은 흰색형을 쓴다   [APPROVED by 조성아, 2026-10-21]
- 범위: SCR-05
- 결정: 카카오는 노란 바탕형, 네이버는 흰 바탕 + 초록 N 표시형.
- 근거: NFR-11 대비 4.5:1. 네이버 초록 바탕 흰 글자는 2.3:1.
- 금지: 초록 바탕 흰 글자 네이버 버튼
- 예외: 네이버가 제공하는 공식 버튼 이미지를 그대로 쓰는 경우는 사람이 확인한 뒤 새 번호로 정한다
- 버린 대안: 두 버튼 모두 브랜드 바탕색

### UX-D-09: 회원 화면에는 빨간(경고) 버튼을 쓰지 않는다   [APPROVED by 조성아, 2026-10-21]
- 범위: 회원 화면 전체 (특히 SCR-18 [구독을 마무리합니다], SCR-12·15 [취소 요청])
- 결정: 회원이 하는 행동은 기본 또는 외곽선 버튼으로 둔다. 빨간 외곽선 버튼은 관리자 [환불]에만 쓴다.
- 근거: INV-13(해지 방어 없음), [근거: REQ-045~047] 붙잡지 않고 편하게 떠나기
- 금지: 해지·취소 요청 버튼을 빨간색·경고 아이콘으로 표시
- 예외: 관리자 [환불]
- 버린 대안: 위험 행동을 빨간색으로 강조(회원에게 겁을 주는 해지 방어처럼 보임)

### UX-D-10: 대체 표지는 테마 무늬 그림으로 그린다   [APPROVED by 조성아, 2026-10-21]
- 범위: `ProductCard`, 상세 표지, 장바구니·서가 표지
- 결정: 이미지가 깨지면 테마 바탕색 + 테마 무늬(자연 잎, 식문화 그릇, 생태 물결, 로컬 지붕) + 책 제목을 3:4로 그린다.
- 근거: AC-04-2, NFR-03(같은 비율의 대체 표지), REQ-010(4개 테마)
- 금지: 회색 빈 상자, 깨진 이미지 아이콘
- 예외: 없음
- 버린 대안: 책방 로고 하나로 된 공통 대체 이미지(어떤 책인지 구분이 안 됨)
