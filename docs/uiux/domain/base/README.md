# 기초 문서 (base)

독립서점 우분투북스에 관한 **직접 경험 원본**을 모아두는 폴더입니다.
UI/UX 에이전트는 이 폴더의 문서를 근거로 `../knowledge.md`(구조화된 지식)를 만들며, 이 폴더의 파일은 **수정하지 않고 읽기만** 합니다.

## 파일 규칙

| 파일 | 개수 | 내용 | 템플릿 |
|---|---|---|---|
| `00-overview.md` | 1개 | 바뀌지 않는 사실(기본 정보, 용어), 전체적인 생각 | `../templates/overview.template.md` |
| `exp-NNN-<짧은제목>.md` | 경험마다 1개 | 한 번의 방문·행사·사건 | `../templates/experience.template.md` |

- ID는 `exp-001`부터 순서대로 붙이고, 한 번 붙인 번호는 바꾸거나 다시 쓰지 않습니다. (근거 표시 `[근거: exp-003 §2]`가 깨지지 않게)
- 경험 내용을 나중에 고칠 때는 파일 맨 아래에 `수정: YYYY-MM-DD, 무엇을 고쳤는지`를 남깁니다.
- 새 경험을 추가하면 아래 목록에도 한 줄 추가합니다.
