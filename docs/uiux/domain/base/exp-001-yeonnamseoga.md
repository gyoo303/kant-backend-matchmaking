## §1. 한 줄 요약

연남서가는 내가 처음 방문한 독립서점으로, 정갈한 공간이 친구의 개인 서재를 구경하는 듯한 인상으로 남아 있음. (직접/생각)

## §2. 장면 (시간 순서대로, 직접 본 것)

1. 2020년 4월 오전 11시쯤 연남서가를 방문했음. 정확한 날짜는 기억나지 않음. (직접)
2. 도착했을 때 문이 닫혀 있어 점심을 먹고 다시 방문했음. 영업 시간이 불규칙하다고 느꼈음. (직접/생각)
3. 공간이 깔끔하고 정돈되어 있다고 느꼈음. (직접)
4. 서점을 둘러보며 친구의 개인 서재를 구경하는 듯한 느낌을 받았음. (생각)
5. 어떤 책들을 취급하였는지에 관한 구체적인 기억은 없음. (모름)

## §3. 들은 것

- 이 방문에서 누구에게 어떤 설명을 들었는지는 기억나지 않음. (모름)

## §4. 불편했던 점 / 좋았던 점

- 불편: 오전 11시쯤 방문했을 때 문이 닫혀 있어 점심을 먹고 재방문했음. (직접)
- 좋음: 정돈된 공간과 책이 놓인 분위기가 마음에 들었음. (직접)
- 해석: 책과 공간을 함께 구경하는 경험이 친근하게 느껴졌음. (생각)
