## 경험 1건의 기준

- **한 번의 방문, 한 번의 행사, 하나의 사건**을 파일 하나로 쓴다.
- 같은 날 두 가지 일이 있었다면(예: 책 구매와 북토크) 성격이 다르면 파일을 나눈다.
- 짧아도 괜찮다. 장면 하나만 있어도 경험 기록 1건이다.

## 출처 표시 (문장마다)

- `(직접)` 내가 직접 보거나 겪은 것
- `(들음: 누구)` 사장님·직원·손님에게 들은 것
- `(생각)` 내 해석이나 의견
- 모르면 비워두지 말고 `모름`이라고 쓴다.

| 내 역할 | 손님 / 행사 참여자 / 관찰자 / 직원 중 선택 → (예시) 손님 |

## §1. 한 줄 요약
(예시) 어떤 신간이 들어왔는지 몰라서 그냥 가봤는데, 손글씨 메모를 읽다가 계획에 없던 책을 샀다. (직접)

## §2. 장면 (시간 순서대로, 직접 본 것)
1. (예시) 가기 전에 인스타에서 신간을 찾아보려 했지만 게시물을 한참 내려도 못 찾았다. (직접)
2. (예시) 도착하니 입구 옆 '이달의 책장'에 주제 카드가 붙어 있었다. (직접)
3. (예시) 책마다 꽂힌 메모를 10권 정도 읽었고, 30분쯤 머물렀다. (직접)
4. (예시) 메모 내용이 마음에 들어 원래 사려던 것과 다른 책을 샀다. (직접)

## §3. 들은 것
- (예시) 계산할 때 "이번 달 주제는 '느리게 걷기'예요"라고 하셨다. (들음: 사장님)

## §4. 불편했던 점 / 좋았던 점
- 불편: (예시) 방문 전에 신간 목록을 확인할 방법이 없었다. (직접)
- 좋음: (예시) 메모 덕분에 추천을 '받는' 느낌보다 '발견하는' 느낌이었다. (생각)

## §5. 웹사이트와 연결되는 생각
- (예시) 이달의 책장 주제와 메모를 웹에서 미리 볼 수 있으면 방문할 이유가 생길 것 같다. (생각)
- (예시) 다만 메모를 전부 웹에 올리면 직접 가서 발견하는 재미가 줄어들 수도 있다. (생각)

## §6. 모르는 것 / 확인할 것
