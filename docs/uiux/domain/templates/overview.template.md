# [작성 가이드] 서점 개요 템플릿 (파일 1개만 유지)

> ⚠️ 이 파일은 **작성 예시**입니다. `(예시)` 문장은 형식을 보여주려고 지어낸 것이라 우분투북스의 실제 정보가 아닙니다.
> 복사해서 `docs/uiux/domain/base/00-overview.md`로 저장하고, 예시 문장은 지운 다음 직접 확인한 내용으로 채워주세요.

## 개요 파일에 쓰는 것 / 쓰지 않는 것

- **쓰는 것**: 방문할 때마다 바뀌지 않는 사실(기본 정보, 용어), 여러 경험을 겪고 난 뒤의 전체적인 생각
- **쓰지 않는 것**: 특정한 날의 장면. 장면은 경험 기록(`exp-NNN`)에 쓰고, 여기서는 ID로 연결만 한다.

출처 표시는 경험 기록과 같다: `(직접)`, `(들음: 누구)`, `(생각)`, 모르면 `모름`.

# 00. 우분투북스 개요

## §0. 작성 정보
- 작성자: 조성아
- 마지막 수정일: YYYY-MM-DD
- 전체 경험 범위: (예시) 2025-09 ~ 2026-09, 손님으로 방문 약 20회, 북토크 2회 참여. 직원으로 일한 적은 없음.
- 이 문서들로 알 수 없는 것: (예시) 매출, 재고 관리 방식, 온라인 주문 비율

## §1. 기본 정보 (확인된 것만)

| 항목 | 내용 | 출처 |
|---|---|---|
| 위치 / 접근성 | (예시) 역에서 걸어서 10분, 골목 안 2층 | (직접) |
| 영업 시간 / 휴무 | 모름 | |
| 규모 | (예시) 책장 10개 정도, 좌석 6석 | (직접) |
| 운영자 | (예시) 사장님 1명, 주말에 직원 1명 | (직접) |
| 지금 쓰는 온라인 채널 | (예시) 인스타그램(신간·행사 공지), DM(주문·행사 신청) | (직접) |

## §2. 서점에서 쓰는 말

| 용어 | 뜻 | 관련 경험 | 출처 |
|---|---|---|---|
| (예시) 이달의 책장 | 매달 주제를 정해 따로 꾸미는 책장 | exp-001, exp-004 | (직접) |
| (예시) 책 메모 | 사장님이 책에 꽂아두는 손글씨 추천 글 | exp-001 | (직접) |

## §3. 여러 경험을 겪고 난 전체적인 생각
- §3-1. 이 서점을 한 문장으로: (예시) "추천받는 곳이라기보다 발견하는 곳" (생각, 관련: exp-001, exp-003)
- §3-2. 웹사이트에 바라는 것: (예시) 와보고 싶게 만드는 사이트 (생각)
- §3-3. 웹사이트가 절대 이러면 안 되는 것: (예시) 할인율·판매 순위가 먼저 보이는 대형 온라인 서점 같은 화면 (생각)
- §3-4. 사장님이 말한 바람: (예시) "온라인으로 많이 팔기보다, 와보고 싶게 만들고 싶다" (들음: 사장님, exp-002)

## §4. 모르는 것 / 확인할 것
- (예시) 온라인 판매를 실제로 원하는지, 예약만 원하는지 → 사장님께 확인 필요
- (예시) 주 고객 연령대: 내 느낌일 뿐 근거 없음
